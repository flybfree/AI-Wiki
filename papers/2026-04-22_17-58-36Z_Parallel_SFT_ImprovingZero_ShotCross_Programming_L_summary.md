## Summary
Parallel-SFT targets zero-shot transfer of code RL across programming languages. It uses parallel programs in supervised fine-tuning to make representations more functionality-centric, which improves transfer to unseen languages after RL.

## Key Takeaways
- RL trained on one source language can fail to transfer to other programming languages.
- Parallel-SFT injects functionally equivalent code in multiple languages during SFT.
- The resulting model generalizes better to unseen languages after RL.


## Context
The paper studies how programming skills learned in one language can be transferred to lower-resource languages.

## Implications
A better SFT initialization can make later RL more transferable across programming languages.
