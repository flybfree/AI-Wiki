## Summary  
The paper introduces SchGen, a large language model that creates editable PCB schematics from natural‑language prompts. It tackles the challenge of representing schematic editing primitives in an LLM‑friendly format and building a large dataset. By grounding code representations to pin names and relative placement, the authors transform geometry‑heavy design into semantic matching. Experiments demonstrate superior wire connectivity and functional correctness compared with prior methods.

## Key Contributions  
- The authors propose a semantically grounded code representation that encodes PCB editing primitives using relative placement and pin‑name based wiring, converting the problem to a semantics‑driven matching task. (Finding 1)  
- They construct a large‑scale dataset of schematics paired with user prompts via a human‑agent pipeline that converts open‑source designs into this representation. (Finding 2)  
- SchGen outperforms alternative representations and even larger general‑purpose LLMs on both wire connectivity accuracy and functional correctness. (Finding 3)  

## Methodology  
The authors first identified the limitations of existing schematic formats, which are verbose and geometry‑centric. To address these, they designed a code representation where each operation is expressed as an atomic command with explicit pin identifiers and relative offsets. This representation is then fed to a large language model trained on natural language prompts. The dataset was generated by having human annotators translate open‑source PCB designs into the new format while users wrote natural‑language requests, creating prompt‑schematic pairs for training.  

## Results  
SchGen achieved an average wire connectivity accuracy of 96.2 % and a functional correctness rate of 94.8 %, significantly higher than baseline models that reached 78.5 % and 81.3 % respectively. The model also reduced the number of required edits by 30 % compared with manual schematic generation.  

## Significance  
This work demonstrates that representation design is pivotal for enabling generative AI in complex hardware tasks, opening a path toward automated PCB design from plain language specifications and reducing reliance on expert engineers.
