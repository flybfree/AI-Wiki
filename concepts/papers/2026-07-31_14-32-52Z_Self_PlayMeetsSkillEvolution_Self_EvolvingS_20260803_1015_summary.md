## Summary
The paper introduces Self-Evolving Skill-Augmented Agent (SESA), a novel framework that integrates persistent procedural memory into the self-play training loop of large language models. By allowing a challenger agent to generate problems and a solver agent to retrieve and apply skills, SESA creates a bidirectional feedback loop where failures are distilled into reusable knowledge that co-evolves with the task distribution. This approach addresses the limitation of traditional self-play methods, which lack persistent state to guide future practice based on historical errors. The system enables both memory-free deployment through parameter updates and optional inference-time retrieval from an external skill bank.

## Key Contributions
- **Co-Evolutionary Training Loop**: SESA establishes a dynamic cycle where task generation and skill memory evolve together; failures in solving inform the creation of new skills, which in turn alter the difficulty and distribution of future problems posed by the challenger.
- **Dual-Mode Knowledge Utilization**: The framework uniquely allows procedural knowledge to be absorbed into the model’s parameters during on-policy training while simultaneously maintaining an external bank of skills, offering flexibility for both efficient deployment and enhanced inference performance.
- **Superior Benchmark Performance**: SESA demonstrates significant accuracy improvements over existing self-play (SSP) and skill-augmented baselines across seven open-domain and multi-hop question-answering benchmarks, proving the efficacy of evolving memory in complex reasoning tasks.

## Methodology
The authors design a dual-agent architecture consisting of a challenger and a solver with separate parameters. The challenger generates training problems without relying on external benchmarks, while the solver attempts to solve them using tool-augmented search. Crucially, when the solver fails, these informative failures are analyzed and distilled into reusable skills that are written back to an external memory bank. This updated memory directly influences the solver’s future behavior and success rates, which subsequently affects the challenger’s reward signal. Consequently, the distribution of problems generated by the challenger shifts to target new frontiers of difficulty, creating a continuous loop of mutual adaptation between problem complexity and skill acquisition.

## Results
Experimental evaluations across seven open-domain and multi-hop question-answering benchmarks show that SESA improves average accuracy by 1.2 to 3.2 points compared to the Self-Play with Search (SSP) baseline across multiple model backbones. It also surpasses the SkillRL baseline by 0.9 points under a unified evaluation protocol. Specifically, on Qwen3 models, the offline variant (SESA-Off) retains an improvement of 1.8–2.2 points over SSP, while adding the final skill bank provides an additional 0.5–1.0 points of gain. These results confirm that evolving skill memory significantly enhances both policy learning and final performance.

## Significance
This work is significant because it demonstrates that procedural memory is not merely a static plug-in for inference but a dynamic component that fundamentally changes the training distribution and policy learning process. By enabling models to learn from their own failures in a structured way, SESA offers a scalable path to improving reasoning capabilities without relying on curated human datasets or fixed task distributions.
