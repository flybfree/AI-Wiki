## Summary  
Federated fine‑tuning suffers from high communication costs because gradient transmission scales with model size, limiting scalability. The authors propose Federated Lightweight Fine‑Tuning (FLITE), which replaces the full weight updates with a low‑bandwidth latent representation generated by a frozen affine projection. By averaging these latents instead of weights, they achieve an 8718× reduction in payload while preserving accuracy. FLITE also introduces a delta formulation and a lightweight orthogonal classifier head to further shrink communication.

## Key Contributions  
- [Finding 1] The method maps network weights from a small trainable latent via a frozen affine projection, enabling exact averaging of generated weights without transmitting full model parameters.  
- [Finding 2] A low‑rank, seed‑regenerable factorisation reduces generator memory from ~80 GB to ~10 MB and cuts communication payload to ~5 KB per client round.  
- [Finding 3] The delta formulation θ = θ^{pre} + U V^T z learns additive corrections around a centrally pretrained base, allowing federated fine‑tuning with negligible bandwidth overhead.

## Methodology  
The authors address the bottleneck of gradient communication by decoupling weight updates from model parameters. A shared frozen affine projection converts a tiny trainable latent into full network weights; because the map is linear and shared, averaging the latents yields the same result as averaging the weights. To keep memory usage low, they factorise this projection with a low‑rank decomposition that can be regenerated from a seed. The delta formulation adds an additive correction term learned locally, while an orthogonal classifier head is frozen to eliminate its contribution from the payload.

## Results  
On CIFAR‑100 using ResNet‑18+GroupNorm, FLITE reaches 74.67% accuracy—within ~0.5 pp of full‑weight FedAvg. Communication drops to 1,280 floats (~5 KB) per client round, an 8718× reduction. Integer‑quantised latents (int4) require only 648 bytes with unchanged accuracy, whereas int4 full‑weight FedAvg collapses to chance. The averaging identity holds to floating‑point precision (≈6 × 10⁻⁸).

## Significance  
FLITE demonstrates that federated learning can operate at scale without prohibitive bandwidth demands, preserving model performance while dramatically lowering communication overhead. This is crucial for real‑world deployments where network resources are limited and models cannot be fully transmitted.
