## Summary  
The paper aims to create an agentic AI‑driven immersive virtual reality (VR) training platform that enables safe, hands‑free learning of high‑dose rate (HDR) vaginal cylinder brachytherapy. A core innovation is a knowledge‑aware assistant built on Retrieval‑Augmented Generation (RAG), which grounds every interactive response in authoritative clinical guidelines while providing real‑time guidance during simulated procedures. The system integrates VR, mobile computing and a local GPU‑accelerated AI backend to deliver low latency and high‑precision support for trainees.

## Key Contributions  
- Knowledge‑aware AI agent using Retrieval‑Augmented Generation (RAG) to provide accurate, guideline‑based feedback during immersive training.  
- Immersive VR environment that simulates HDR brachytherapy without the need for physical radioactive sources or facility constraints.  
- Prototype architecture on Meta Quest 3 with a local GPU backend achieving sub‑100 ms end‑to‑end latency and high context precision.

## Methodology  
The authors approached the problem by designing a hybrid agentic system where an LLM‑powered assistant retrieves relevant clinical knowledge via RAG, then interacts with the VR/AR interface. The solution is implemented locally on a GPU‑accelerated backend to keep data private and latency low; the front‑end uses a Meta Quest 3 headset linked to a mobile device for hands‑free navigation and real‑time guidance during simulated brachytherapy maneuvers.

## Results  
The prototype demonstrates end‑to‑end latency under 100 ms, answer completeness exceeding 90 % and relevance scores above 8/10. Simulated trainees performed procedural tasks with minimal error compared to physical practice, indicating that the knowledge‑aware agent provides reliable, real‑time support without compromising immersion.

## Significance  
This work bridges metaverse AI and medical education by offering a scalable, radiation‑free training platform for complex brachytherapy techniques. By reducing exposure risks and procedural errors, it can improve trainee competence and safety while leveraging the immersive potential of VR to accelerate skill acquisition.
