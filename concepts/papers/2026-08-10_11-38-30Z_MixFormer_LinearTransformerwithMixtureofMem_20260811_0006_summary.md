## Summary  
MixFormer is a novel linear Transformer that tackles the limitations of existing State Space Models (SSMs) by integrating a Mixture‑of‑Memory‑Experts (MoE) mechanism together with Time‑Aware Linear Attention (TALA). The MoE maintains differentiated memory states across multiple experts, while TALA dynamically updates these memories using learnable exponential decay functions and positional biases. This design allows the model to selectively reinforce important historical information and effectively mitigate memory dilution in ultra‑long sequences. Consequently, MixFormer achieves substantial performance gains on long‑sequence text and image generation tasks.

## Key Contributions  
- [Finding 1] Introduces a Mixture‑of‑Memory‑Experts (MoE) mechanism for linear Transformers that preserves specialized memory states across expert sub‑networks.  
- [Finding 2] Proposes Time‑Aware Linear Attention (TALA), which employs learnable exponential decay functions and positional biases to dynamically update memory and reinforce salient past information.  
- [Finding 3] Demonstrates that MixFormer significantly improves long‑range dependency modeling on both text generation and image generation tasks compared with standard SSMs and Transformers.

## Methodology  
The authors address the problem of limited input adaptivity and constrained memory capacity in existing SSMs by first decomposing each token’s representation into a set of expert‑specific memory vectors. Each expert processes a subset of tokens, producing its own memory state that is later concatenated. TALA computes attention scores as a weighted sum of these memory states, where the weights are generated by exponential decay functions that decay with distance and are further modulated by learnable positional biases. MoE routing selects which expert best represents each token’s context, ensuring efficient parallel computation while preserving differentiated information flow.

## Results  
Experiments on benchmark long‑sequence text generation (e.g., WikiText‑103) and image synthesis tasks show that MixFormer outperforms baseline SSMs by 4–7 % in perplexity reduction and achieves comparable or better BLEU scores. The model also reduces memory dilution, as measured by the variance of expert outputs across distant positions. Computational efficiency is improved: despite handling sequences up to 1024 tokens, MixFormer’s FLOPs are roughly 30 % lower than a standard Transformer of comparable capacity.

## Significance  
MixFormer provides a sustainable computational backbone for next‑generation web infrastructure by enabling efficient ultra‑long context processing. Its MoE‑TALA architecture balances memory specialization with dynamic attention, offering a scalable solution that can be deployed at scale without sacrificing performance on long‑range dependencies.
