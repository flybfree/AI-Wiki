**## Summary**  
The paper tackles the fundamental flaw in federated fine‑tuning of Vision Transformers (ViTs) that employ low‑rank adapters (LoRA): aggregating heterogeneous client LoRA factors leads to mathematically inconsistent results and either high server bandwidth or costly weight reinitialization. To resolve this, the authors introduce **SpecTraL**, a spectral transformation framework that discovers optimal layer‑wise global ranks without manual hyperparameter tuning. By applying an orthonormal Householder transformation directly in the low‑rank latent space, SpecTraL eliminates dense reconstruction of global updates and auxiliary refinement on the server. The method also leverages the Spiked Covariance Model from Random Matrix Theory to separate consensus signals from non‑IID noise, enabling a unified design that preserves communication efficiency while maintaining model stability.

**## Key Contributions**  
- [Finding 1] SpecTraL resolves cross‑term aggregation errors by performing an orthonormal Householder transformation on stacked local LoRA adapters in the low‑rank latent space.  
- [Finding 2] The approach eliminates dense reconstruction of global updates and any server‑side auxiliary refinement, thereby reducing bandwidth and computational overhead.  
- [Finding 3] By applying the Spiked Covariance Model from Random Matrix Theory, SpecTraL analytically separates the global consensus signal from non‑IID noise, allowing optimal layer‑wise rank discovery without hyperparameter search.

**## Methodology**  
The authors first stack the local LoRA modules generated by each client into a single matrix. They then apply an orthonormal Householder transformation to this stacked tensor, which effectively projects the combined adapters onto an orthogonal basis in the low‑rank latent space. This spectral decomposition yields a set of global ranks that correspond to the dominant singular components. To accommodate residual LoRA dimensions across rounds, they employ a padding‑aware initialization framework that allows clients to retain their original adapter sizes without merging them into the pre‑trained base model. The process repeats iteratively, updating only the selected low‑rank components identified by the spectral transformation.

**## Results**  
Experiments on federated fine‑tuning of ViT‑B/16 and ViT‑L/16 over DomainNet and NICO++ demonstrate that SpecTraL improves accuracy while maintaining a lower communication cost compared to existing aggregation strategies. Server computation is reduced, and the need for manual rank selection disappears; the optimal ranks are automatically discovered each round. The method also avoids reinitializing pretrained weights, leading to more stable convergence.

**## Significance**  
SpecTraL matters because it provides a principled, communication‑efficient solution for federated LoRA fine‑tuning of ViTs that does not suffer from cross‑term errors or costly weight updates. By integrating spectral theory with practical initialization tricks, the approach simplifies deployment and scales to heterogeneous client environments without sacrificing model performance.
