## Summary  
The paper introduces PAWNI, a multi‑agent conversational system that helps users formulate high‑quality prompts for complex tasks by asking guided questions. It uses an eight‑agent architecture and a three‑tier prompt framework to clarify intent before feeding the LLM. Experiments show participants generate more complete prompts and receive higher‑quality outputs with lower workload compared to unassisted prompting. The study demonstrates that front‑loading prompt formulation improves human‑AI collaboration.

## Key Contributions  
- PAWNI’s multi‑agent conversational interface reduces the number of iterative prompting turns needed for complex tasks.  
- A three‑tier prompt framework (Essential, Enhancement, Elevation) with 18 elements systematically guides users to include all relevant information.  
- Experimental results show participants achieve satisfactory LLM output in a single turn versus 1–12 turns unaided, with higher NASA‑TLX scores and better perceived quality.

## Methodology  
The authors designed PAWNI as an eight‑agent system that iteratively asks clarifying questions to users while updating a self‑evolving knowledge base. They collected data from four participants across four complex tasks using 32‑channel EEG, NASA‑TLX workload assessment, and behavioral metrics, measuring prompt completeness, LLM output quality, and participant workload.

## Results  
In the within‑subjects study (N=4), prompts produced by PAWNI were 42–91 % complete across the 18 elements, LLM outputs scored higher on all quality dimensions, NASA‑TLX scores dropped from 21.7 to 39.6, and participants reached satisfactory output in a single turn versus 1–12 turns unaided.

## Significance  
By optimizing prompt formulation front‑end, PAWNI reduces cognitive load, improves task success rates, and enhances the efficiency of human‑AI collaboration, offering a scalable framework for integrating LLMs into complex problem solving.
