## Summary  
The paper introduces a “Universal Activation Bus” that creates a common activation interface across multiple language models, eliminating the need to rebuild probes or sparse autoencoders for each new model. By learning a shared dense space together with a lightweight linear encoder‑decoder adapter pair per model, the framework enables activation‑based tools to be reused seamlessly. The key innovation is that after an initial source model is trained, its interface is frozen and subsequent models join by fitting only their own adapter on unlabeled matched text. This allows intermediate activations from one model to be consumed by another’s frozen upper layers for prediction.

## Key Contributions  
- [Finding 1] A universal activation bus provides a common activation interface across compatible language models using a shared dense space and a single lightweight encoder‑decoder adapter pair per model.  
- [Finding 2] The interface is frozen after source training; new models join the system by fitting only their own adapter on unlabeled matched text, without retraining existing tools.  
- [Finding 3] Intermediate activations learned in one model can be directly used by another model’s frozen upper layers to generate predictions.

## Methodology  
The authors begin with a set of source language models that share similar architectures and training objectives. They jointly train these models on a common corpus while simultaneously learning a shared dense representation space. To capture the mapping between each model’s hidden states and this dense space, they introduce one lightweight linear encoder‑decoder adapter pair per model. After the source phase is complete, all adapters are frozen, forming a stable activation contract. When a new model is introduced, it only needs to be trained on unlabeled text that matches the style of the existing models; its adapter is fitted while the shared space and other tools remain unchanged. This approach leverages common probes, sparse autoencoders, and natural‑language interpreters without modification.

## Results  
Experiments across five different language models demonstrate that semantically related texts form consistent neighborhoods in the shared activation space. An onboarded model can reuse existing activation‑based tools—such as common probes, SAE features, and an NLA originally trained for a different model—without any retraining. Moreover, activations generated by one model’s encoder can be fed into the frozen upper layers of another model to produce accurate predictions, showing that the interface is both stable and functional across models.

## Significance  
This work establishes a stable, model‑wise activation contract that enables reusable tools across compatible language models, dramatically reducing development time for probes, autoencoders, and interpreters. By allowing intermediate activations to flow between frozen layers, it opens new possibilities for cross‑model knowledge transfer and efficient tool deployment.
