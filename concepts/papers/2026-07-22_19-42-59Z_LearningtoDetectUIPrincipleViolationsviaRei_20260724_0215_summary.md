## Summary  
This paper addresses a critical gap in the evaluation of web front-end code generated by small language models and coding agents, which often produce functional but visually or accessibility-poor interfaces that violate established UI quality principles. The authors propose a lightweight vision-language model trained via reinforcement learning to detect these violations, offering an efficient alternative to costly human reviews or expensive frontier models. By integrating 19 principles from HCI literature into a verified dataset of synthetic web pages, the system learns to score interface quality beyond mere functional correctness. This approach enables scalable, automated auditing and feedback for design-aware code generation.

## Key Contributions  
- [Finding 1] A unified framework combining WCAG 2.2 accessibility standards, deceptive design taxonomies, and cognitive-interaction theories into a single set of 19 UI principle violations.  
- [Finding 2] The development of a large-scale synthetic dataset of ~10,000 web pages with injected known violations into clean LLM-generated Tailwind interfaces for training.  
- [Finding 3] A reinforcement learning process that significantly improves detection accuracy on a 4B vision-language model, raising micro-F1 from 36% to 84%, with 13 principles exceeding 80% F1.

## Methodology  
The authors began by compiling a comprehensive set of UI quality principles drawn from three authoritative sources: WCAG 2.2 for accessibility compliance, deceptive design taxonomies (e.g., Nielsen’s Heuristics), and established theories in perception, cognition, and human-computer interaction. To train the critic model, they generated clean web pages using Tailwind CSS and synthetically injected known violations into these templates, creating a dataset where each page is annotated with which principles are violated. The reinforcement learning process involved iteratively optimizing a 4B vision-language model to maximize detection performance across all 19 principles by providing rewards based on correct identification of violations.

## Results  
The trained critic achieved a micro-F1 score of 84% in identifying UI principle violations, a substantial improvement over the baseline of 36%. Specifically, 13 out of the 19 principles were detected with F1 scores above 80%, indicating high reliability. The model demonstrated strong performance across diverse violation types, including accessibility barriers and poor visual hierarchy, suggesting broad applicability. These results validate the effectiveness of reinforcement learning in enhancing a lightweight vision-language model for UI quality assessment.

## Significance  
This work introduces a scalable, automated method to evaluate the quality of web interfaces generated by AI systems, moving beyond functional correctness to include perceptual and cognitive dimensions of user experience. By providing a reward signal for design-aware code generation, it can improve the output of coding agents, reducing the need for expensive human audits while maintaining high accuracy. The approach supports reproducible research through open data-generation recipes and prompts, fostering future work in AI-assisted UI design.
