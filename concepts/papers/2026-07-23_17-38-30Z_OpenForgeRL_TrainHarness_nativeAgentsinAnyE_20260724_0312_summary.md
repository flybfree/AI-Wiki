## Summary  
OpenForgeRL introduces a lightweight proxy‑based framework that enables end‑to‑end training of agents built on complex inference harnesses such as Claude Code, Codex, and OpenClaw within any arbitrary environment. By decoupling the harness’s model calls from the RL training loop, the authors can record these interactions as data for standard RL codebases (e.g., veRL) while executing rollouts in isolated Kubernetes containers. This separation allows researchers to train, study, and improve agents directly on the real harnesses and environments they will later deploy, without needing custom‑engineered pipelines. The framework is validated across multiple harnesses and use‑cases, achieving state‑of‑the‑art performance on both tool‑based and multimodal GUI benchmarks.

## Key Contributions  
- [Finding 1] OpenForgeRL provides a generic proxy that records harness model calls as training data for conventional RL agents.  
- [Finding 2] The Kubernetes orchestrator runs each rollout in its own remote container, enabling scalable, isolated execution across diverse environments.  
- [Finding 3] Experiments show that harness‑specific RL improves agentic reliability (self‑verification, tool coverage) and multi‑step planning, though error recovery remains a challenge.

## Methodology  
The authors built OpenForgeRL by first constructing a proxy service that intercepts every model inference request from the harness, logs the input, output, and metadata, and forwards them to an RL trainer. The proxy is deployed as a Kubernetes pod per rollout, ensuring no state leakage between tasks. Rollouts are generated by standard RL algorithms (e.g., PPO) using the logged data as experience replay. This modular design lets any harness be plugged in without modifying the training stack.

## Results  
OpenForgeClaw reaches 31.7 pass³ and 55.9 pass@3 on ClawEval, 33.7 on QwenClawBench; OpenForgeGUI scores 37.7 (OSWorld‑Verified), 63.0 (Online‑Mind2Web), 72.3 (WebVoyager). These results outperform comparable open baselines and match or exceed larger models, demonstrating the framework’s effectiveness across tool‑based and GUI agents.

## Significance  
By abstracting harness inference into a trainable data stream, OpenForgeRL lowers the barrier to training sophisticated multi‑step agents in real hardware, accelerating research on agent reliability and deployment readiness. It also provides a reproducible benchmark for comparing different harnesses and RL algorithms under identical conditions.
