## Summary  
Flow‑based generative models have reached impressive performance on continuous and discrete tasks but are limited to fixed output dimensions or sequence lengths. The authors introduce Expanding Generative Flows (EFlows) that create interpolants whose dimensionality grows by appending conditional noise, then propose Expanding Flow Maps (EFMs) as a factorized two‑step model using an expand operator and a transport map. This construction unifies existing fixed‑canvas flows and enables controllable output size. The framework is extended to the discrete simplex for variable‑size graph generation.

## Key Contributions  
- Introduce Expanding Generative Flows (EFlows) that define interpolants with increasing dimensionality via conditional noise augmentation.  
- Propose Expanding Flow Maps (EFMs) as a factorized two‑step generative model using learnable expand and transport operators, preserving existing fixed‑canvas flows.  
- Extend the framework to the discrete simplex enabling variable‑size graph generation and variable‑length sequence generation.

## Methodology  
The authors construct an expanding interpolant that grows the state space by appending conditional noise coordinates or tokens. EFMs are formed by composing a learnable expand operator (which augments dimensions) with a transport map (which pushes forward along the interpolant). Both operators are trained jointly to produce a single flow between any two timesteps, allowing the model to simultaneously expand and denoise.

## Results  
Experiments on continuous diffusion tasks show that EFMs achieve comparable or better generation quality with fewer steps than baseline fixed‑canvas flows while retaining controllability. On discrete graph generation using simplex interpolation, EFMs produce diverse graphs of variable size with consistent quality across lengths, demonstrating the framework’s versatility and efficiency.

## Significance  
This work provides a principled way to treat output dimensionality as a learned degree of freedom, opening new possibilities for generative models that can adaptively expand state spaces without sacrificing speed or fidelity. By unifying continuous and discrete settings, EFMs could enable flexible applications such as variable‑length storytelling, dynamic scene composition, and scalable graph synthesis.
