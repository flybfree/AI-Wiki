## Summary  
The paper addresses the challenge of assigning credit to internal units of a fixed skill, such as rules or examples, when agents are optimized by automated feedback loops that generate long structured artifacts. It proposes SkillSV, a structure‑aware Shapley‑style valuation method that treats skills as composed of interdependent components within a hierarchy. By separating content value from context cost and using rollout‑budgeted estimators, the framework can evaluate only valid counterfactual deletions. The approach enables agents to understand which skill units truly contribute to performance, supporting safe pruning or compression without harming overall utility.

## Key Contributions  
- Finding 1: SkillSV introduces a structure‑aware Shapley‑style framework for skill valuation that respects the internal organization of skills.  
- Finding 2: The method compiles skills into units, records dependencies and hierarchy, then applies paired deletion with length‑neutral padding to isolate content value from context cost.  
- Finding 3: Empirically, SkillSV recovers unit interactions, preserves aggregate skill lift across benchmarks, and provides clear explanations that guide safe pruning or compression.

## Methodology  
The authors fix an agent and a held‑out task distribution, then decompose each skill into its constituent units (e.g., rules, examples) while capturing how these units depend on one another. They construct a dependency graph and a hierarchical representation of the skill. To evaluate the contribution of each unit, they perform paired deletion: temporarily remove a unit and pad the remaining content with neutral tokens to keep prompt length constant, thus separating the cost of context from the value of the deleted unit. The resulting gains are estimated using a rollout‑budgeted estimator that accounts for noisy agent evaluations.

## Results  
Across four agentic benchmarks, SkillSV demonstrates high faithfulness: it accurately identifies which unit deletions cause performance drops and preserves the overall skill lift when multiple units are removed together. The explanations generated by the framework are actionable, allowing practitioners to prune or compress skills safely without sacrificing utility. In particular, the method’s length‑neutral padding ensures that context cost is not conflated with content value, leading to reliable counterfactual valuations.

## Significance  
Accurate skill valuation is crucial for automated feedback systems that continuously refine agents; it enables transparent credit allocation and prevents over‑optimization of low‑value components. By providing a principled, structure‑aware measure, SkillSV supports efficient compression and safe pruning, reducing computational load while maintaining performance.
