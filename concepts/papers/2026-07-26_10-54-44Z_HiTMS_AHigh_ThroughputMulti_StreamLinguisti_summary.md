## Summary  
The paper introduces HiTMS, a high‑throughput multi‑stream linguistic steganography framework that spreads secret bits across several responses generated by a single language model call. By embedding and extracting multiple streams within each batched interaction, HiTMS amortizes the cost of model invocations and dramatically improves throughput compared with single‑stream baselines while preserving exact recoverability. The authors demonstrate that eight‑stream HiTMS can be up to 4.3 times faster than existing methods and reduces the steganalyzer AUROC from 0.681 to 0.601 on average, with gains persisting as concurrency rises to 4–64 streams.

## Key Contributions  
- [Finding 1] HiTMS distributes a secret across multiple responses produced jointly over successive rounds of interaction, enabling batched multi‑stream inference.  
- [Finding 2] The framework uses self‑describing frames and a key‑derived schedule that binds each stream to a slot and fills unused slots with decoys, guaranteeing exact recovery while concealing the number of active streams.  
- [Finding 3] HiTMS is agnostic to both the language model and the steganographic coder, achieving sustained throughput improvements across a wide range of concurrency levels.

## Methodology  
The authors approached the problem by recognizing that existing single‑stream schemes cannot support batched inference or conceal slot occupancy. They therefore designed HiTMS to operate within a single batched call: each round embeds several streams simultaneously and extracts them later, using a schedule derived from a shared secret key. The scheme wraps every response in a self‑describing frame that records the number of active streams and decoy slots, ensuring that steganalysis cannot infer how many bits are hidden. Because the framework does not depend on any specific model or coder, it can be applied generically to large language models.

## Results  
Across eight dataset‑model‑coder settings, HiTMS with eight streams achieved up to 4.3 times higher embedding and extraction speeds than single‑stream baselines. The average steganalyzer AUROC dropped from 0.681 to 0.601, indicating a statistically significant reduction in detection probability. Additional experiments showed that throughput gains remained robust when the number of streams varied from four to sixty‑four, confirming that concurrency increases do not degrade performance.

## Significance  
HiTMS matters because it tackles two critical limitations of prior linguistic steganography: lack of protocol support for batched inference and inability to hide slot occupancy. By distributing secret bits across multiple responses, the framework improves real‑world latency and throughput while maintaining strong stealth guarantees. This enables practical deployment in high‑throughput applications such as secure chatbots or content distribution where many users interact with a single model.

## Related Concepts  
- Linguistic steganography: hiding data within language models’ outputs.  
- Generative models: large language models that generate text probabilistically.  
- Batched inference: processing multiple inputs in a single forward pass to reduce overhead.  
- Multi‑stream inference: extracting several secret streams from one model call.  
- Self‑describing frames: metadata that records the number and location of hidden bits.  
- Decoy slots: filler bits used to obscure the true count of active streams.
