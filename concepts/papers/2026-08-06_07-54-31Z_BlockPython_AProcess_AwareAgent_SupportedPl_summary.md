## Summary  
BlockPython is a process‑aware platform that bridges the gap between block‑based visual programming and Python text‑based syntax for learners. It provides bidirectional translation between blocks and Python code while guiding users through four progressive stages: Task Decomposition, Block‑Based Practice, Code Challenge, and Extended Interaction. The system continuously collects evidence such as block artifacts, code versions, run outcomes, support usage, and dialogue to diagnose comprehension difficulties. By combining deterministic execution, program visualization, and an adaptive learning assistant, BlockPython offers a systematic design reference for supporting the transition from visual to textual programming.

## Key Contributions  
- [Finding 1] The platform implements a process‑aware framework that continuously gathers evidence across all four learning stages, enabling real‑time diagnosis of learner difficulties.  
- [Finding 2] A rule‑based execution engine drives deterministic program evaluation and stage progression, ensuring consistent assessment of computational concepts.  
- [Finding 3] The learning assistant leverages verified evidence to generate explanations, prompts, and guiding questions that adapt to the learner’s specific struggles.

## Methodology  
The authors approached the problem by first outlining a four‑stage learning workflow that scaffolds the transition from block structures to Python syntax. They designed a bidirectional translation engine that maps visual blocks to equivalent Python expressions and vice versa. Evidence collection is embedded at each stage, capturing artifacts, code revisions, execution results, support interactions, and dialogue logs. The deterministic rule system executes programs, evaluates objectives, and controls stage flow, while the learning assistant interprets this evidence to provide targeted assistance.

## Results  
The experimental evaluation demonstrates that learners using BlockPython achieve a higher degree of linkage between program structure, runtime behavior, and textual code compared with control groups. Theoretical analysis of the collected process evidence shows that early‑stage misalignments are most effectively addressed through adaptive prompts generated by the learning assistant. The framework’s deterministic execution guarantees reproducible outcomes, allowing for reliable assessment of learning progress.

## Significance  
BlockPython matters because it addresses a well‑documented cognitive gap in educational technology: the difficulty learners face when converting visual block representations into abstract Python syntax. By providing evidence‑driven support and a clear procedural scaffold, the platform not only improves immediate comprehension but also offers a reusable design model for future transition tools.
