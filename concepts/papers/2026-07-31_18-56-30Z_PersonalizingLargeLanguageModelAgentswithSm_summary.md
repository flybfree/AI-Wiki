## Summary  
The paper tackles the challenge of personalizing large language model agents so that their execution decisions—such as memory retrieval, tool invocation, and response style—adapt to individual users without retraining the whole LLM. It introduces FABLE (Factorized Adaptive Bandit Layer for Execution), a lightweight policy layer that learns per‑user residual preferences from scalar feedback using Bayesian contextual Thompson sampling under a linear residual‑reward model. The approach delivers an expected‑regret bound, anytime‑valid false‑promotion control, and preserves end‑to‑end task performance while improving preference‑sensitive behaviors.

## Key Contributions  
- FABLE factorizes memory, information acquisition, and response decisions into separate components that can be updated online from scalar feedback.  
- It learns user‑specific residual preferences relative to a fixed default‑and‑cost score via Bayesian contextual Thompson sampling, achieving an expected‑regret bound under linear residual‑reward assumptions.  
- The method provides anytime‑valid false‑promotion control and characterizes cases where user preferences are unidentifiable due to persistent feasibility constraints.

## Methodology  
The authors treat personalization as online learning of a per‑user execution policy. FABLE is placed as a lightweight layer outside the frozen LLM host, allowing only scalar feedback for executed actions to update the policy. Memory retrieval is handled by an external module that supplies context; information acquisition is modeled as a bandit problem with feasible action sets; response decisions are generated by Thompson sampling on residual scores derived from a default‑and‑cost baseline plus user residuals.

## Results  
Experiments across personalized reasoning, controlled feedback, and executable tool use show FABLE improves preference‑sensitive behaviors (e.g., more accurate recall, appropriate style) compared to rule‑only baselines. Theoretical analysis confirms an expected‑regret bound against the best feasible action when a linear residual reward model holds. The agent’s end‑to‑end task performance remains competitive with non‑personalized baselines.

## Significance  
By enabling cheap, online personalization of LLM agents without retraining large models, FABLE opens possibilities for privacy‑preserving and scalable user‑centric AI systems that adapt to individual preferences while maintaining robustness. It also clarifies the limits of preference learning under feasibility constraints, aiding future research.
