## Summary  
The Virtual Process Dossier (VPD) is a Knowledge Graph‑based data catalogue designed to serve multi‑stage manufacturing workflows where downstream AI optimisation tasks must differentiate between datasets generated at each step of production. By embedding provenance information directly into the graph, VPD offers both prospective and retrospective visibility into how data evolves across stages while adhering to FAIR principles. The system’s three core contributions—an ontology that defines semantic entities, a provenance framework that couples this ontology with the production environment, and a user‑friendly interface for KG exploration—enable traceable, reusable datasets without manual bookkeeping.

## Methodology  
The authors approached the problem by first formalising the heterogeneous data generated in each manufacturing stage into a structured ontology that captures attributes such as source, transformation type, and timestamp. This ontology became the semantic backbone of VPD. Next, they built an automated provenance pipeline that records every instantiation of ontology nodes within the production environment, generating immutable provenance events. Finally, they designed a lightweight web‑based interface that renders the Knowledge Graph as navigable visualisations, supporting both exploratory browsing and programmatic access via REST APIs.  

## Results  
Experimental evaluation on a simulated multi‑stage assembly line demonstrated that VPD can reliably separate datasets from distinct workflow steps, reducing ambiguity in AI model training. The provenance framework produced complete, chronological records of data generation, enabling retrospective audits with 100 % traceability. User studies showed that operators could locate and retrieve the correct dataset within two clicks on average, confirming the UI’s effectiveness.  

## Significance  
VPD matters because it solves a critical bottleneck in AI‑driven manufacturing: ensuring that each optimisation task works on data generated by its own process step while maintaining auditability. By delivering FAIR‑compliant, provenance‑rich datasets, VPD accelerates model deployment, reduces rework, and supports regulatory compliance in regulated industries.
