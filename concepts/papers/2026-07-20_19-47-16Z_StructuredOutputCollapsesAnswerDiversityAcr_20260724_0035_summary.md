## Summary  
This paper investigates how imposing a structured output format—specifically “Reply with JSON only”—alters the diversity of answers generated by 44 language models across a set of 31 one‑word prompts. By comparing unconstrained responses to those constrained to JSON, the authors demonstrate that the modal answer becomes markedly more prevalent while distinct alternatives dwindle, indicating a systematic collapse of answer variety. The study also reveals that this effect is driven by register‑indexed defaults rather than decoder constraints and that the compression incurred is modest but statistically significant.

## Key Contributions  
- [Finding 1] Structured output (JSON) raises the modal answer frequency from 41 % to 64 % of the response pool and reduces the number of distinct answers from 52 to 36, indicating a sharpening rather than re‑indexing.  
- [Finding 2] Six out of 44 models shift individually toward the mode (BH‑FDR q = 0.10), while the conformist floor remains unchanged; JSON also reverts many stable chat defaults to crowd‑driven answers, showing that format changes are not merely surface edits but affect underlying response tendencies.  
- [Finding 3] Compression measured by surprisal drops –0.22 bits for JSON (p < .001), –0.19 bits for XML, no change for YAML/CSV, and a slight increase (+0.13) for an arbitrary bracket wrapper; schema enforcement adds only –0.03 bits, confirming that the collapse resides in model response to format registers rather than decoder constraints.

## Methodology  
The authors re‑run the One‑Word Census experiment (originally arXiv:2607.12796) with 44 language models and 31 prompts. For each prompt they collect two versions of the answer: one unrestricted and one forced into JSON format, without any schema enforcement or constrained decoding. They compute modal frequency, distinct answer count, mean surprisal, and run BH‑FDR tests to identify models whose behavior changes beyond random noise (q = 0.10). The study also varies output formats (JSON, XML, YAML, CSV, bracket wrapper) to quantify compression effects.

## Results  
Across all prompts the modal answer dominates 64 % of JSON responses versus 41 % in unconstrained mode; distinct answers fall from 52 to 36. Mean surprisal declines from 1.80 bits to 1.58 bits. Six models exhibit individual shifts toward the mode, and a within‑run re‑sample (n = 20) shows JSON reverts 53 % of a model’s stable chat defaults. Compression is significant for JSON (‑0.22 bits, p < .001), XML (‑0.19 bits, p < .002), and reversed for a bracket wrapper (+0.13 bits, p = .009); YAML/CSV show no change. Enforcing the JSON schema at the decoder adds only –0.03 bits of compression.

## Significance  
The findings demonstrate that structured output collapses answer diversity in a way that is measurable and systematic across diverse models. The collapse is not merely a decoding artifact but reflects register‑indexed defaults, suggesting that the surface representation used for evaluation (JSON) is more homogeneous than the chat‑style surface on which models are compared. This matters because software that consumes language models must account for this format‑induced bias when selecting or ranking systems.
