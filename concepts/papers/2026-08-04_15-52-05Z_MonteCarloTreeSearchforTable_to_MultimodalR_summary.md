## Summary  
The paper introduces **MCTS‑Report**, a Monte Carlo Tree Search (MCTS) framework that generates professional multimodal reports from structured tabular data while jointly optimizing factual accuracy, visual quality, and narrative coherence. By decomposing report generation into atomic actions—chapter planning, visualization task identification, chart creation, insight organization, and narrative refinement—the authors enable an LLM to produce step‑by‑step reasoning guided by the current report state. A multi‑dimensional reward function steers the search toward factually consistent SQL queries, high‑quality charts, good chart‑text alignment, structural completeness, diversity (avoiding repeated visuals), and precondition checks that prune invalid actions. The method is evaluated on **MMRBench**, a benchmark of real‑world tables across six domains with expert‑refined reference reports.

## Key Contributions  
- [Finding 1] Introduces MCTS‑Report, a progressive construction process that treats multimodal table‑to‑report generation as a search over a structured space composed of atomic actions.  
- [Finding 2] Designs a joint multi‑dimensional reward function that combines SQL‑based factual consistency, chart quality metrics, chart‑text alignment, structural completeness, a diversity penalty to suppress repeated charts, and precondition checks for pruning invalid actions.  
- [Finding 3] Constructs **MMRBench**, a comprehensive benchmark with real‑world tables from six domains paired with expert‑refined reference report structures and verifiable key insights.

## Methodology  
The authors model the problem as a search over a tree where each node stores the reasoning trajectory generated by an LLM. The LLM outputs candidate atomic actions conditioned on the current report state, and these are evaluated by the reward function. Nodes violating preconditions or generating duplicate charts are pruned using the diversity penalty. The search proceeds iteratively, expanding nodes with higher scores until a high‑quality report is constructed. This approach allows the system to explore many possible report structures while maintaining coherence through the stored reasoning history.

## Results  
Experiments on MMRBench show that MCTS‑Report achieves an overall score of **77.9**, significantly outperforming strong baselines in four evaluation dimensions: structural completeness, numerical accuracy, chart‑text alignment, and insight novelty. The gains are consistent across all six domains, indicating robust performance. Quantitative comparisons reveal improvements of 5–12 percentage points over the best prior methods, confirming that the MCTS framework effectively balances multiple objectives.

## Significance  
This work advances data intelligence by providing a principled search mechanism for generating multimodal reports that do not treat textual and visual components in isolation. By jointly optimizing factual accuracy, visual quality, and narrative flow, MCTS‑Report produces higher‑quality insights that are more useful to end users. The framework also demonstrates how tree‑based planning can be combined with large language models to solve complex, multi‑task generation problems.
