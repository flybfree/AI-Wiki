## Summary  
Ordinal regression is commonly used when labels are discrete yet have a meaningful order, but in practice these labels often arise from subjective human judgments that create ambiguous boundaries and annotation noise. Existing methods rely on static supervision targets, which can reinforce those very biases instead of learning robust ordinal representations. To overcome this limitation, we introduce D3O—a dynamic distribution distillation framework that replaces fixed supervision with training‑driven evolution of ordinal label distributions via self‑distillation. The core idea is to continuously refine the label space so that the network learns a more faithful representation of the underlying continuous semantics.

## Key Contributions  
- [Finding 1] D3O employs dynamic distribution distillation, replacing static supervised targets with an evolving ordinal label distribution generated by the model itself.  
- [Finding 2] A contrastive ordinal‑aware label enhancement module leverages vision‑language alignment to recover refined label distributions that capture both inter‑class ambiguity and instance‑level uncertainty.  
- [Finding 3] A CDF‑based cross‑layer interaction distillation mechanism propagates the cumulative ordinal structure across network hierarchy, ensuring consistent ordinal geometry in intermediate representations.

## Methodology  
The authors address the problem by constructing a self‑distillation loop that continuously updates label distributions rather than using them as fixed anchors. First, a contrastive loss aligns predicted ordinal scores with the true distribution while encouraging the model to distinguish between ambiguous classes. Second, a vision‑language encoder refines these labels through joint training, reducing noise and ambiguity. Third, they introduce CDF‑based cross‑layer interaction distillation: each layer computes the cumulative distribution function of its output scores and passes this information to adjacent layers, preserving ordinal ordering throughout the network. The entire pipeline is trained end‑to‑end on the ordinal regression task.

## Results  
D3O consistently outperforms existing approaches on four general ordinal regression benchmarks, especially when class imbalance or noisy supervision is severe. Quantitative evaluations show higher accuracy and F1 scores compared to baseline methods that rely on static labels. The authors also report improved robustness to label noise, indicating that the dynamic distillation process mitigates the influence of subjective annotations.

## Significance  
Dynamic supervision sidesteps the bias introduced by fixed ordinal targets, allowing models to learn representations that better reflect the true continuous ordering. This is crucial for real‑world applications where labels are imperfect and context‑dependent. By providing a principled way to evolve label distributions during training, D3O opens the door to more reliable ordinal predictions beyond traditional static learning paradigms.
