## Summary  
The paper introduces the “Workbook Time Machine,” a pipeline that automatically generates spreadsheet‑manipulation benchmarks to evaluate language models’ ability to create formulas, charts, pivot tables, and conditional formatting. It builds a large corpus (wtmcorpus) of input‑output‑query triples spanning four artifact types with varying complexity, then curates a 150‑task benchmark (wtmbench) that varies query specificity. The study demonstrates that how specific the task is, how agents orchestrate steps, and which interface API controls the spreadsheet all strongly affect LLM performance on Excel tasks.

## Key Contributions  
- Founding the workbook time machine pipeline for automatic generation of spreadsheet‑manipulation benchmarks.  
- Creating wtmcorpus—a collection of (input workbook, output workbook, query) triples that span four artifact types and varying complexity levels.  
- Discovering that task difficulty is driven primarily by query specificity, agent orchestration, and interface API rather than solely by model capability.

## Methodology  
The authors designed a pipeline that takes publicly available workbook corpora and applies systematic transformations to produce paired output workbooks together with natural‑language queries. This generates wtmcorpus, which the researchers then curate into wtmbench, selecting 150 tasks across artifact types (formulas, charts, pivot tables, conditional formatting) and complexity levels. Tasks are generated by varying the granularity of instructions and the number of required steps, allowing systematic exploration of how specificity influences performance.

## Results  
Evaluation across three query‑specificity levels shows a clear drop in LLM accuracy as tasks become more specific; conversely, less specific queries yield higher scores but lower utility. Orchestration experiments reveal that single‑step prompts outperform multi‑step pipelines for many artifact types, while explicit step‑by‑step instructions improve results on pivot tables and charts. API‑level tests (Excel vs. Google Sheets) demonstrate that the underlying spreadsheet engine influences outcomes, especially for conditional formatting. Overall, performance varies significantly by artifact type, with chart generation being the most challenging.

## Significance  
The workbook time machine provides a standardized benchmark for evaluating AI agents’ spreadsheet manipulation abilities, enabling fair comparison across models and prompting strategies. By isolating variables such as query specificity, orchestration, and API choice, the study clarifies which design choices degrade or enhance performance, guiding future research on LLM‑driven spreadsheet tools.
