## Summary  
The paper proposes **G‑ReAct**, a graph‑guided deep search framework that treats reasoning as state evolution over a fixed‑topology query graph, thereby preserving intermediate states and constraints during long‑horizon multi‑hop tasks. By generating high‑quality training trajectories and providing structured guidance at inference time without additional fine‑tuning, G‑ReAct mitigates context forgetting and search drift. Experiments show that the framework yields strong performance on benchmark datasets such as BrowseComp‑ZH (52.6 % accuracy) and XBench (79.0 % accuracy), outperforming comparable open‑source methods—including RL‑enhanced approaches—trained on much larger corpora.  

## Key Contributions  
- **Graph‑structured state evolution**: Introduces a model that explicitly tracks search progress as a graph state, turning exploratory textual history into constrained reasoning.  
- **Dual‑mode training and inference**: Provides both supervised fine‑tuning using generated trajectories (≈1.9 K) and inference‑time guidance without extra fine‑tuning.  
- **Benchmark superiority**: Achieves higher accuracy than comparable methods, especially RL‑enhanced ones, on deep‑search benchmarks.  

## Methodology  
The authors model the query as a static graph where nodes represent entities and edges encode relations. Each search step updates a *graph state* that records visited nodes and active constraints. This state is fed to a learned policy or attention mechanism that selects subsequent tokens, ensuring decisions are guided by the current graph context rather than only by the textual history. Training leverages a small set of high‑quality trajectories generated by G‑ReAct itself; inference reuses the same graph‑state logic to produce structured reasoning steps.  

## Results  
On **BrowseComp‑ZH**, fine‑tuned Qwen3‑30B‑A3B‑Thinking‑2507 reaches 52.6 % accuracy, surpassing other methods trained on substantially larger datasets. On **XBench**, the same model attains 79.0 % accuracy. When applied at inference time to strong LLMs, G‑ReAct consistently improves deep‑search performance across tasks without requiring additional fine‑tuning or compute overhead.  

## Significance  
G‑ReAct bridges the gap between open‑domain reasoning and efficient search by providing a scalable mechanism to maintain context in long trajectories. It reduces reliance on heavy RLHF or massive fine‑tuning, enabling reliable LLM applications for browsing, multi‑step problem solving, and other complex tasks where intermediate states must be preserved.
