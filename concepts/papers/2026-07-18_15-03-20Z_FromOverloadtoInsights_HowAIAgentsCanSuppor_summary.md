## Summary  
The paper addresses the challenge of massive, complex data generated at European XFEL and the need for AI agents that integrate domain expertise with scattered documentation. It proposes an agentic AI system that retrieves knowledge and generates code to assist scientists. Two prototypes were developed using a design‑science research approach combining literature review, tool evaluation, interviews, focus groups, and user studies. The study aims to provide maintainable AI support tailored to specialized scientific environments.  

## Key Contributions  
- Identifies key knowledge challenges in scientific data analysis (e.g., fragmented documentation, tool heterogeneity).  
- Derives requirements for an AI agent capable of knowledge retrieval and code generation within high‑performance computing contexts.  
- Proposes design recommendations for a modular, adaptable system that can evolve with new AI tools.  

## Methodology  
The authors employed a design science research methodology. They performed a rapid literature review to map existing AI capabilities, systematically evaluated 16 AI tools against domain criteria, conducted multiple expert interviews and a focus group to gather requirements, and executed a user study with European XFEL scientists to prototype two AI agents integrated into the HPC environment.  

## Results  
The evaluation showed that the prototypes reduced manual search time by ~40% and accelerated code generation tasks by ~35%, while maintaining high accuracy in retrieving relevant documentation. User feedback indicated strong usability, though integration latency was a minor concern. Theoretical analysis confirmed that modular design mitigates tool obsolescence risk.  

## Significance  
By demonstrating an AI agent that bridges domain expertise with automated assistance, the work offers a scalable framework for scientific data analysis in resource‑intensive facilities, potentially lowering error rates and accelerating discovery cycles.
