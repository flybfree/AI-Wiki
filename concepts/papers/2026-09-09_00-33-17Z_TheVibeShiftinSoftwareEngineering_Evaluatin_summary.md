## Summary  
This paper investigates Vibe Coding, an AI‑led conversational programming paradigm that lets developers generate code through natural‑language dialogue with large language models. The authors aim to assess how this approach influences performance efficiency, cognitive load, and responsible adoption relative to traditional coding and conventional AI‑assisted tools. Using a mixed‑methods experimental design, they compare three conditions among thirty participants to quantify trade‑offs in software quality and user experience. Their findings suggest that while Vibe Coding boosts productivity, it also introduces challenges for maintainability and security that require careful oversight.

## Key Contributions  
- [Finding 1] Vibe Coding reduces task completion time by 27 % compared with traditional coding and 12 % versus AI‑assisted coding, indicating a clear performance gain.  
- [Finding 2] The same efficiency boost is accompanied by lower maintainability indices and higher security vulnerabilities, revealing quality trade‑offs.  
- [Finding 3] Usability scores (SUS = 71.4) are good while cognitive workload remains moderate (NASA‑TLX = 55.5), and themes of trust calibration, loss of control, cognitive adaptation, and prompt‑engineering emerge as central constructs.

## Methodology  
The authors employed a mixed‑methods approach: quantitative data were gathered via descriptive statistics and repeated‑measures ANOVA across three experimental conditions; qualitative insights came from thematic analysis of open‑ended responses. Participants comprised thirty professional developers and advanced computing students who completed equivalent programming tasks under the traditional, AI‑assisted, and Vibe Coding conditions.

## Results  
Quantitatively, Vibe Coding achieved a 27 % reduction in task time versus traditional coding and a 12 % improvement over AI‑assisted coding. However, maintainability indices dropped significantly and security vulnerability counts rose sharply. Qualitative analysis yielded a SUS score of 71.4 (good usability) and an NASA‑TLX workload of 55.5 (moderate), suggesting reduced syntactic effort but increased linguistic reasoning. Thematic coding identified trust calibration, loss of control, cognitive adaptation, and prompt‑engineering strategy as key constructs.

## Significance  
These results underscore that AI‑led conversational programming can dramatically accelerate development while also eroding software quality and user confidence if not properly managed. The study calls for a balanced integration strategy that preserves productivity gains without sacrificing maintainability or security, highlighting the need for responsible adoption frameworks in modern software engineering.
