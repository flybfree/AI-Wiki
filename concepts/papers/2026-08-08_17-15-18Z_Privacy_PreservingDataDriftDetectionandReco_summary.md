## Summary  
ProxyDrift addresses the core challenge of large‑scale LLM deployments: detecting drift between production user traffic and offline evaluation sets while respecting privacy constraints that forbid direct inspection of raw data. The authors propose a framework that operates entirely on non‑PII proxy representations—structured descriptors generated by an LLM classifier—and provides mechanisms for continuous monitoring, synthetic data generation, and taxonomy refinement. By integrating mutual information‑based alignment scores and conditional sampling, ProxyDrift achieves tight end‑to‑end alignment with production traffic without exposing sensitive user interactions. This enables large‑scale drift detection and recovery while preserving privacy.

## Key Contributions  
- [Finding 1] The framework identifies and measures drift between production traffic and offline evaluation sets using only non‑PII proxy representations, eliminating the need to access raw user data.  
- [Finding 2] A chance‑calibrated, redundancy‑aware (RA) alignment score aggregates per‑dimension drift measurements via mutual information, delivering a reliable metric for continuous monitoring.  
- [Finding 3] A conditional sampler generates synthetic proxies that respect inter‑dimensional dependencies, allowing targeted recovery of evaluation sets without compromising privacy.

## Methodology  
ProxyDrift begins by converting each user interaction into a structured proxy descriptor through an LLM classifier, producing multi‑dimensional values that capture the interaction’s class and confidence. The RA alignment score computes mutual information across dimensions to quantify drift per dimension while accounting for redundancy. A conditional sampler then creates synthetic proxies that preserve these dependencies, ensuring the generated set remains consistent with the original distribution. Roundtrip consistency analysis compares the classifier’s output on real vs. synthetic data to detect generator‑classifier disagreements and guides taxonomy refinement. Finally, feedback‑linkage analysis links per‑dimension proxy distributions to user satisfaction signals, surfacing actionable success or failure modes.

## Results  
Experiments deployed across hundreds of millions of users confirm strong roundtrip consistency between real and synthetic queries. Discriminator‑level tests show that synthetic queries are indistinguishable from human‑generated ones at the discriminative level. The RA alignment score achieves a tight end‑to‑end correlation (RA ≈ 0.9) with production traffic, demonstrating precise drift detection. The conditional sampler successfully refreshes evaluation sets without exposing raw data, enabling continuous monitoring and targeted recovery.

## Significance  
ProxyDrift provides a privacy‑preserving solution for large‑scale LLM applications that must maintain model performance while complying with strict data protection regulations. By delivering reliable drift metrics and synthetic data generation on proxy representations alone, it reduces reliance on sensitive user information and supports ongoing model evaluation without compromising confidentiality.
