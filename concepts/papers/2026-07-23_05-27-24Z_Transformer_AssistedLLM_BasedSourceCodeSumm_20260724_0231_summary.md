## Summary  
The paper proposes Transformer‑Assisted LLM‑Based Source Code Summarisation to generate natural‑language summaries of code that are both high‑quality and useful for secure software development. It addresses the mismatch between lexical overlap (measured by BLEU) and semantic fidelity, showing that embedding a task‑specific Transformer output into an LLM prompt can boost summary quality. The authors demonstrate this hybrid approach on four LLMs using distinct prompts, achieving measurable gains over baseline LLM‑only summarisation.  

## Key Contributions  
- Combining LLM abstractive summarisation with task‑specific Transformer outputs via prompt engineering yields higher BLEU‑4 and BLEU‑5 scores than LLMs alone.  
- The method leverages the Transformer’s lexical generation capability to steer the LLM toward summaries that align more closely with human‑written code descriptions.  
- Experiments show a 7.8 % increase in BLEU‑4 and a 5 % increase in BLEU‑5 compared with LLMs without assistance, indicating improved summary fidelity.  

## Methodology  
The authors prompt four large language models (LLMs) using four different instruction prompts that embed summaries generated by a small task‑specific Transformer model as part of the text. This hybrid setup exploits the Transformer’s ability to produce concise, relevant code snippets while the LLM expands them into natural language. The evaluation consists of comparing these hybrid summaries against LLMs that generate summaries without any Transformer assistance on a benchmark set of source‑code pairs.  

## Results  
The hybrid approach achieves a 7.8 % increase in BLEU‑4 and a 5 % increase in BLEU‑5 relative to the baseline LLM‑only method, indicating better lexical alignment with human summaries while preserving semantic meaning. Additionally, perplexity remains comparable or slightly lower, suggesting that the Transformer assistance does not degrade overall generation quality.  

## Significance  
By enabling LLMs to produce more accurate and contextually appropriate code summaries on workstation hardware, this approach supports timely maintenance within the Secure Software Development Lifecycle (SSDLC), thereby reducing the likelihood of bugs and vulnerabilities introduced during later stages. The method bridges the gap between abstractive generation and practical utility for developers who need concise yet meaningful documentation.
