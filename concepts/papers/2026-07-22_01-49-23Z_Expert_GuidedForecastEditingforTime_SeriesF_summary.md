## Summary  
The paper addresses the challenge of improving time‑series forecasts generated by frozen foundation models using limited expert feedback. It proposes DEFT, a framework that balances exploitation of model predictions with structured exploration guided by an expensive evaluator. By decomposing trajectories into trend and seasonal components, DEFT reuses expert scores across recombined samples to reduce query cost. The approach consistently outperforms pure best‑of‑N and optimization methods under matched query budgets.  

## Key Contributions  
- [Finding 1] DEFT introduces a decomposed trend–seasonal editing paradigm that reuses expert scores across recombined forecast samples.  
- [Finding 2] The framework balances pure exploitation with structured component‑wise refinement, reducing the number of required expert queries.  
- [Finding 3] Experimental results show DEFT improves forecast quality across multiple benchmarks and query budgets compared to state‑of‑the‑art methods.  

## Methodology  
The authors start with a frozen time‑series foundation model that generates candidate trajectories in a low‑dimensional trend–seasonal space. Each candidate is a recombination of trend and seasonal components sampled from the model’s predictive distribution. An expert evaluator scores complete trajectories, providing feedback on both components. DEFT then selects a set of recombined samples to query the expert, reusing scores for each component that appears in multiple queries. This enables efficient exploitation while allowing targeted exploration around promising regions.  

## Results  
We evaluate DEFT against best‑of‑N, cross‑entropy search, and Bayesian optimization on 78 heterogeneous datasets using three foundation models, four feedback types, and seven query budgets. Across all settings, DEFT achieves the highest average forecast error reduction (≈12 % lower MAE) compared to baselines. The molecular‑dynamics case study demonstrates that the same principle yields gains when expert feedback is sparse and physically constrained.  

## Significance  
By reusing expert scores across component recombinations, DEFT reduces query cost without sacrificing performance, making test‑time guidance scalable for large models. This work provides a template for integrating structured, low‑cost feedback into frozen generative models, which could be applied to forecasting, recommendation, and other sequential domains.
