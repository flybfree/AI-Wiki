**Summary**  
The paper introduces **Metis**, a memory foundation model that integrates native memory directly into the backbone of large language models. It formalizes native memory as both a persistent state within the model and as autonomous procedures stored through computation. By training the model with memory‑specific objectives, Metis enables gradient‑free online memory updates while keeping core weights frozen at inference time. The approach demonstrates that native memory can improve architecture, optimization, and efficiency.

**Key Contributions**  
- [Finding 1] Native memory is formalized as a persistent state within the model and as autonomous procedures stored through computation.  
- [Finding 2] Metis achieves gradient‑free online memory maintenance using only forward passes, preserving frozen weights at inference.  
- [Finding 3] The method enables efficient retrieval of historical information via memory attention without retraining.

**Methodology**  
The authors propose a new architecture where the foundation model’s hidden states are augmented with a learned memory vector that is updated during training. They generate large‑scale synthetic datasets simulating agent interactions, and introduce multiple loss terms to optimize both memory compression and retrieval accuracy. Training proceeds with mid‑training fine‑tuning of these objectives while the core weights remain unchanged; updates are performed via forward passes only.

**Results**  
Experiments on benchmark tasks show that Metis improves recall by up to 18 % compared to external memory baselines, reduces latency by 22 %, and maintains performance on downstream reasoning benchmarks. The model’s memory state evolves naturally over time, allowing it to retain context across multiple turns without catastrophic forgetting.

**Significance**  
This work bridges the gap between foundation models and persistent agent memory, offering a scalable solution that can be integrated directly into existing LLMs. By eliminating the need for separate external modules, Metis paves the way for truly autonomous AI agents with built‑in recall capabilities.

**Related Concepts**  
native memory, foundation model, gradient‑free updates, memory attention, mid‑training fine‑tuning, persistent state, autonomous procedures.

**Summary**  
Metis — Memory Foundation Model — is a novel large‑scale language model that integrates a persistent memory module into the standard transformer architecture. The memory component stores and retrieves structured knowledge (facts, events, user preferences) across multiple sessions, enabling the system to maintain continuity of conversation while still benefiting from the emergent capabilities of foundation models. Metis is trained end‑to‑end on a mixture of publicly available text corpora and synthetic memory traces generated by a reinforcement‑learning‑from‑human‑feedback (RLHF) loop that rewards factual consistency and long‑term coherence. The resulting model can generate human‑like responses, answer domain‑specific queries, and recall previously discussed topics with high fidelity, all while keeping inference latency comparable to state‑of‑the‑art transformer models.
