## Summary
This paper introduces Mixture-of-Translators (MoT), a novel framework designed to enable the reuse of Key-Value (KV) caches across heterogeneous Large Language Models (LLMs). Current multi-model systems suffer from inefficiency because KV caches are model-specific, forcing redundant prefilling or storage for shared contexts. MoT addresses this by mapping context KV caches from a source LLM into the compatible cache space of a target LLM using multiple specialized translator modules rather than a single projection path. The authors identify and mitigate two critical failure modes in cache translation—propagated translation shift and last-state shift—through a combination of translator mixtures and a Context Correction Loss. This approach significantly enhances the scalability of multi-model reasoning and long-context generation by allowing quality-preserving memory reuse across different architectures.

## Key Contributions
- **Introduction of Mixture-of-Translators (MoT):** The paper proposes a framework that uses multiple translator modules to capture diverse source-to-target mappings, overcoming the limitations of prior methods that rely on single projection paths or global shared latent spaces.
- **Identification of Failure Modes:** The authors reveal two competing failure modes in cache translation: "propagated translation shift" caused by early injection errors and "last-state shift" caused by late injection errors. MoT specifically addresses these through its mixture architecture and target-side correction mechanisms.
- **Context Correction Loss:** A new loss function is introduced to align the replayed target trajectory with the native target trajectory, significantly reducing residual translation errors and ensuring the translated cache maintains high fidelity.
- **Demonstrated Cross-Architecture Compatibility:** The framework successfully enables KV cache reuse across heterogeneous models, including Qwen2.5, GPT-2, and OPT, preserving downstream performance in tasks like closed-set QA and extractive QA.

## Methodology
The authors approach the problem of heterogeneous KV cache incompatibility by designing a translation framework that decouples the source and target model architectures. Instead of forcing a direct mapping, MoT employs an ensemble of translator modules that learn diverse mappings between source and target cache spaces. To handle the inherent noise and drift in such translations, the methodology incorporates a Context Correction Loss. This loss function acts as a corrective mechanism during training, ensuring that the translated cache, when replayed in the target model, produces outputs that closely match those generated by the target model’s native processing of the same context. The evaluation involves both homogeneous and heterogeneous translations across various model scales and architectures, testing the robustness of the translation against downstream tasks like Question Answering.

## Results
Experimental results demonstrate that MoT effectively preserves downstream QA performance across heterogeneous models. Specifically, when translating caches for Qwen2.5-7B-scale models, the system achieved an average closed-set QA accuracy of 51.0% and an average extractive QA F1 score of 0.43. In practical case studies involving multi-agent reasoning, MoT enabled quality-preserving memory reuse, allowing agents to share context without redundant computation. Furthermore, in long-context cache-augmented generation scenarios, the framework retained 96.3% of the quality achieved by direct-context generation, proving its viability for scalable, long-context applications. These results indicate that the translation errors introduced by cross-model mapping are sufficiently minimized to maintain high utility in real-world applications.

## Significance
This work is significant because it tackles a fundamental bottleneck in the deployment of heterogeneous LLM systems: the inability to share computational state (KV caches) across different model architectures. By enabling scalable KV cache reuse, MoT reduces the computational overhead associated with repeated prefilling and storage, which is critical for multi-agent systems and long-context applications. This advancement facilitates more efficient and collaborative AI systems where different specialized models can leverage shared knowledge and context without incurring prohibitive latency or memory costs. It opens new avenues for building modular, composable LLM pipelines that can dynamically switch models while maintaining continuity of context.

## Related Concepts
- **Key-Value (KV) Caches:** Internal memory structures in Transformers that store attention keys and values to speed up inference.
- **Heterogeneous LLMs:** Systems composed of different model architectures (e.g., Qwen, GPT, OPT) working together.
- **Cache Translation:** The process of mapping internal representations from one model's architecture to another's.
- **Context Correction Loss:** A training objective designed to minimize discrepancies between translated and native model outputs.
- **Multi-Agent Reasoning:** Collaborative problem-solving where multiple LLM agents share context and history.
- **Long-Context Generation:** Generating text based on extensive input contexts, where cache efficiency is crucial.
