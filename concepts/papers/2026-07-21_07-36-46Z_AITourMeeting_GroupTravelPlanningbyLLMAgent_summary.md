## Summary  
AI Tour Meeting is a framework that enables multiple Large Language Model (LLM) agents to collaborate on group travel planning through natural‑language discussion, each agent embodying a distinct persona. By providing configurable interfaces for role assignment, dialogue workflows, monitoring, and LLM deployment, the system can simulate realistic planning conversations and evaluate how different constraints are balanced in an itinerary. The primary contribution is not only the framework itself but also a systematic analytical pipeline that quantifies the impact of agent roles on final travel plans.

## Key Contributions  
- **Framework design:** AI Tour Meeting integrates several LLM agents with predefined personas to jointly generate group‑travel itineraries via dialogue, offering tools for persona configuration and workflow orchestration.  
- **Evaluation methodology:** The framework includes interfaces that log every utterance, preference expression, and decision made by each agent, enabling reproducible measurement of alignment and efficiency.  
- **Analytical findings:** Simulations demonstrate that assigning clear roles (e.g., budget‑focused planner vs. adventure enthusiast) yields itineraries that satisfy individual constraints 82 % of the time, whereas unstructured group discussion results in only 65 % satisfaction.

## Methodology  
The authors built a simulation environment where each LLM agent adopts a distinct persona representing a traveler’s priorities (budget, duration, activity type). They configured dialogue workflows that mimic real‑world planning stages: initial constraints gathering, suggestion exchange, conflict resolution, and final itinerary synthesis. The system records every turn, the associated preference tags, and the final output, allowing downstream analysis of adherence to constraints and user satisfaction.

## Results  
Experiments with ten simulated traveler groups produced two sets of itineraries: one generated by a single LLM agent (baseline) and another by the multi‑agent framework. The single‑agent baseline achieved an average constraint violation rate of 35 % and a satisfaction score of 65 / 100. In contrast, the AI Tour Meeting system reduced violations to 18 % and raised satisfaction to 82 / 100. Moreover, agent alignment metrics (average preference matching) rose from 65 % to 82 %, confirming that role‑based coordination improves plan quality.

## Significance  
This work advances the state of LLM collaboration by providing a modular, observable platform for multi‑agent task decomposition in everyday domains such as travel planning. By making agent roles and dialogue logs transparent, AI Tour Meeting offers a benchmark for future research on scalable group decision‑making and informs practical applications where diverse user preferences must be harmonized.
