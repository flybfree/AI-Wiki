## Summary  
The paper proposes a factorized inverse decision model (FIDM) that infers latent cognitive factors from verbal transcripts, extending existing action‑only inverse models. It decomposes each participant’s task‑execution likelihood into an action component and an effort component, both governed by individual‑specific parameters. Using 400 older adults in a grocery‑shopping dialog task, the model shows selective recovery of intended factors while preserving distinctions between actions and execution. The approach supplies complementary information to clinical scores and language representations for cognitive‑status classification.

## Key Contributions  
- [Finding 1] FIDM separates an action factor from an effort factor with individual‑specific parameters.  
- [Finding 2] On matched semi‑synthetic conditions, FIDM preserves the distinction between actions and execution even when behavioral summaries are aggregated.  
- [Finding 3] Action evidence localizes task‑defined deviations across participants and improves binary cognitive‑status classification.

## Methodology  
The authors constructed a language model that converts raw verbal transcripts into structured task‑execution traces, then applied an inverse decision framework factorizing each participant’s likelihood of completing the task into action and effort components estimated via individual‑specific parameters. Data collection involved 400 older adults performing a grocery‑shopping dialog for cognitive screening.

## Results  
Controlled recovery demonstrated selective estimation of intended factors, while semi‑synthetic matching showed that FIDM preserves action‑execution distinctions even when behavioral summaries are matched. Action evidence localized deviations across participants and yielded consistent gains in binary cognitive‑status classification compared to baselines such as trajectory summaries and frozen language representations.

## Significance  
This work advances inverse decision modeling by incorporating verbal production dynamics, offering a more nuanced assessment of cognitive function beyond traditional behavioral trajectories and providing richer data for clinical screening applications.
