## Summary  
The paper describes a collaboration between the Directorate‑General for Translation (DGT) and the European Master’s in Translation (EMT) to localise the MMLU dataset into 11 European languages, creating an inclusive multilingual benchmark for LLM evaluation. It also serves as a project‑based training platform for master’s students covering translation, revision, project management, and coordination. This work addresses methodological, administrative, and workflow challenges inherent in large‑scale multilingual data preparation. The contribution is both the dataset itself and an educational framework that links research to real‑world practice.

## Key Contributions  
- Creation of an 11‑language European MMLU localisation dataset.  
- Integration of a professional training module for EMT students covering translation, revision, project management, and coordination.  
- Identification of key methodological, administrative, and workflow challenges in multilingual data curation.

## Methodology  
The authors approached the problem by selecting existing MMLU items, translating them into 11 European languages using a hybrid approach that combines human translators with automated tools, then assembling them into a unified dataset. They designed a project timeline with milestones for translation, quality control, metadata tagging, and student supervision to ensure coordinated progress across the network.

## Results  
The localisation was completed across all 11 languages, resulting in a balanced dataset comparable to the original MMLU size. Evaluation shows that the multilingual version maintains performance parity on standard LLM benchmarks while exposing LLM weaknesses in low‑resource European languages.

## Significance  
This dataset broadens the scope of evaluation for LLMs beyond English and major world languages, supporting more equitable AI research. It also provides students with real‑world project experience, bridging academia and industry.

## Related Concepts  
MMLU (Massive Multilingual Multi‑Task Understanding), multilingual localisation, European translation training, LLM evaluation benchmarks, EMT network, project management in translation.
