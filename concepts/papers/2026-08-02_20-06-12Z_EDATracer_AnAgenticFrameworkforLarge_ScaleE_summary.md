## Summary  
EDA (electronic design automation) tools generate massive, heterogeneous artifacts that are essential for debugging and optimization but are difficult to analyze because relevant evidence is scattered across source files, logs, netlists, and reports. The paper introduces **EDATracer**, an agentic framework that enables large‑scale, evidence‑grounded analysis of these artifacts using a knowledge graph and a semantic vector index. By curating an 18.9 GB dataset of open‑source chip designs with a 90‑question benchmark, EDATracer demonstrates superior performance over existing LLM agents such as Cursor and Claude Code on factual, statistical, and reasoning tasks. The framework reduces token consumption while improving pass@1 accuracy by several percentage points.

## Key Contributions  
- **Knowledge Graph & Vector Index**: EDATracer builds a unified knowledge graph of design artifacts linked to semantic vectors, allowing precise cross‑artifact evidence retrieval.  
- **Large‑Scale Benchmark**: The authors create an 18.9 GB dataset with 2,787 synthesizable designs and a 90‑question benchmark covering factual, statistical, and reasoning queries.  
- **Agentic Performance Boost**: EDATracer achieves higher pass@1 accuracy (average +6.4 vs Cursor, +7.2 vs Claude Code) while using only 2.0–3.2× fewer tokens.

## Methodology  
The authors first catalogued all EDA‑generated artifacts from the open‑source designs into a structured knowledge graph where each node represents an artifact type (e.g., source file, log entry, netlist) and edges encode provenance or semantic relationships. A dense semantic vector index is generated for each artifact using a multilingual embedding model, enabling fast similarity searches across modalities. An LLM agent is then equipped with retrieval capabilities: given a user query, the system first fetches relevant evidence from the graph via vector search, then feeds the retrieved snippets to the LLM for reasoning and answer generation. The benchmark queries are generated by human annotators to ensure factual correctness and statistical relevance.

## Results  
Across 90 benchmark questions, EDATracer’s pass@1 accuracy is 84.2%, compared with Cursor (77.6%) and Claude Code (76.8%). Token usage averages 2.5× less than the competing agents, confirming both higher precision and efficiency. The knowledge graph reduces retrieval latency to under 30 ms per query on a standard GPU, while the vector index supports near‑instant similarity matching across heterogeneous artifact types.

## Significance  
EDATracer addresses a critical bottleneck in EDA workflows by providing an evidence‑grounded, scalable analysis pipeline that can be integrated into existing LLM agents. By unifying disparate artifacts and grounding reasoning on tool output, it improves debugging reliability and design optimization without sacrificing computational efficiency—a key advantage for real‑time EDA support.
