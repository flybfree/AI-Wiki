## Summary  
The paper addresses the lack of a common evaluation basis for multi‑agent collaboration traces generated by large language models. By converting these heterogeneous traces into a unified graph representation, ForestBench enables direct comparison across diverse methods without relying on outcome‑only metrics or model‑dependent LLM judges. The framework builds benchmark “forests” that capture multiple successful execution paths per query, providing a reusable structural baseline for assessment. This unified approach streamlines analysis and reduces the need for repeated inference steps.

## Key Contributions  
- [Finding 1] ForestBench introduces a graph‑based representation of collaboration traces that is independent of the underlying LLM or task outcome.  
- [Finding 2] The framework pre‑computes ten reference graphs per query from public datasets, creating a stable set of “successful” graphs for evaluation.  
- [Finding 3] Experimental results show that ForestBench scores a trace in milliseconds and yields consistent rankings across six representative MAS frameworks.

## Methodology  
The authors first extracted $844$ collaboration‑necessary queries from seven public datasets, then constructed ten successful target‑conditioned reference graphs for each query. These graphs serve as the “forest” – a collection of verified‑success interaction patterns. ForestBench scores any new trace by comparing its native graph to this forest using a shared metric panel, eliminating the need for additional LLM inference or rubric changes.

## Results  
Controlled studies on backbone selection, reference construction, and perturbation demonstrate stable performance across all tested methods. The framework reduces evaluation time from minutes to milliseconds while maintaining comparable ranking accuracy to prior outcome‑only benchmarks. The ten reference graphs per query provide a diverse set of successful execution traces that the system can leverage for quick comparison.

## Significance  
By offering a reusable, model‑agnostic graph benchmark, ForestBench simplifies research on multi‑agent collaboration and accelerates method evaluation cycles. It removes reliance on ad‑hoc LLM judges and outcome metrics, fostering fairer, reproducible comparisons that are essential as MAS systems proliferate.
