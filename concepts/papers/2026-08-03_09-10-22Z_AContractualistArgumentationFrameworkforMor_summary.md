## Summary  
The paper proposes a formal contractualist argumentation framework for moral decision‑making, building on Scanlon’s theory that an action is permissible only if no one could reasonably reject the principles it supports. It extends ASPIC+ with value‑based filtering to model how each agent’s values determine which reasons are morally relevant in the first place. The framework represents reasons formally, compares them via argumentation semantics, and evaluates outcomes through a contractualist lens. This work bridges moral philosophy with structured argumentation in shared environments.

## Key Contributions  
- [Finding 1] Formal integration of Scanlon’s contractualism into an argumentation framework.  
- [Finding 2] Extension of ASPIC+ with value‑based filtering to encode agents’ moral values.  
- [Finding 3] Demonstration via a domestic decision scenario showing how the framework selects permissible actions.

## Methodology  
The authors approached the problem by first mapping Scanlon’s principle of no reasonable rejection onto argumentation primitives, then designing an ASPIC+ module that filters reasons according to each agent’s value set before applying standard argumentation evaluation rules. They formalized values as predicates, created a contract‑compatible reason representation, and used a test case involving two household members deciding on resource allocation.

## Results  
The framework yields a decision tree where only arguments respecting the “no reasonable rejection” principle survive; in the example it selects a fair division of chores over an unfair one. Theoretical analysis shows that the filtered reasons align with contractualist permissibility, while standard argumentation metrics confirm consistency.

## Significance  
This work provides a principled method for integrating moral theory into automated reasoning systems, enabling autonomous agents to make ethically sound decisions in collaborative settings and offering a bridge between normative ethics and formal argumentation.
