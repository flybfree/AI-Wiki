## Summary  
The paper addresses the challenge of selecting and ordering a set of skills for LLM agents to solve complex tasks efficiently. It proposes Structured Skill Composition, formalizing skill composition as predicting which skills, how many, and in what order to execute. SkillComposer is introduced as a task‑conditioned autoregressive model that jointly decides subset, count, and execution order. The authors train the model on a human‑curated skill library and evaluate it on downstream coding tasks.

## Key Contributions  
- Finding 1: Structured skill composition is a joint decision over which skills, how many, and their order, which cannot be decoupled.  
- Finding 2: SkillComposer uses a constrained autoregressive decoder to predict the entire skill sequence in one pass, capturing dependencies naturally.  
- Finding 3: The model achieves +23.1 % and +18.2 pp improvement over no‑skill baseline on GPT‑5.2‑Codex and Gemini‑3‑Pro‑Preview, matching gold‑skill retrieval while using fewer prompt tokens.

## Methodology  
The authors built a training set of task‑composition pairs from a real human‑curated skill library. They treat each composition as a sequence of skill identifiers to be generated by SkillComposer’s decoder. The model is trained with standard language modeling objectives, and the constrained decoder ensures only valid skill IDs are emitted.

## Results  
On held‑out test sets, SkillComposer yields higher composition quality scores than retrieval baselines. In SkillsBench, it raises pass rates of GPT‑5.2‑Codex by 23.1 % and Gemini‑3‑Pro‑Preview by 18.2 percentage points compared to a no‑skill baseline, reaching the gold‑retrieval upper bound at lower token cost.

## Significance  
By integrating composition decisions into a single generative model, SkillComposer simplifies agent design, reduces prompt overhead, and improves task success rates across production‑grade coding agents, offering a scalable path toward modular LLM systems.
