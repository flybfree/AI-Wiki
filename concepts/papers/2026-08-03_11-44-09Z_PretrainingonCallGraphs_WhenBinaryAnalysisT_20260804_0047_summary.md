## Summary  
The paper investigates how incorporating inter‑procedural information from a program’s call graph can improve the quality of embeddings generated by binary function embedding models. By extending two state‑of‑the‑art binary function embedding systems with call‑graph context, the authors show that while this refinement boosts performance on binary code similarity detection (BCSD), it does not uniformly benefit downstream tasks such as semantic analysis or syntactic parsing. The study reveals a trade‑off: optimizing for semantic similarity often degrades syntactic performance, indicating that call‑graph pretraining is most valuable in specific, context‑dependent scenarios rather than universally.

## Key Contributions  
- [Finding 1] Call‑graph‑based enhancements increase embedding robustness and improve BCSD scores but do not guarantee gains on all downstream tasks.  
- [Finding 2] Optimizing embeddings for semantic similarity tends to worsen performance on syntactic analysis tasks, highlighting a negative correlation between these objectives.  
- [Finding 3] The added context is most beneficial for functions that involve namespace resolution, whereas it offers limited help for functions focused solely on isolated logic.

## Methodology  
The authors employed a suite of graph‑based models to evaluate embeddings produced by two leading binary function embedding systems (e.g., Binary2Vec and GraphBERT). They integrated inter‑procedural call‑graph information as additional input alongside the primary function representation. Experiments compared three downstream tasks: BCSD, semantic similarity classification, and syntactic parsing of code snippets. The evaluation was performed on a diverse set of binary programs spanning various domains to assess generalization.

## Results  
Incorporating the call graph raised average BCSD F1 scores by roughly 4‑6 % relative to baseline models, demonstrating clear gains in similarity detection. However, when the same embeddings were used for semantic classification or syntactic parsing, performance either stagnated or declined compared with task‑specific pretraining. A detailed dataset analysis showed that functions heavily involving namespace lookups benefited most from call‑graph context, while pure logic functions saw minimal improvement. The trade‑off between semantic and syntactic objectives was quantified, revealing a measurable negative impact on the latter.

## Significance  
The findings underscore that pretraining on call graphs is not a one‑size‑fits‑all solution; its value is contingent on the nature of downstream tasks and the function’s structural characteristics. This work informs future research by suggesting task‑aware integration of inter‑procedural context, potentially leading to more efficient and effective binary analysis models.
