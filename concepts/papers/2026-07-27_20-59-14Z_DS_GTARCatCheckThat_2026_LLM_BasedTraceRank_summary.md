**## Summary**  
The authors tackle the CLEF 2026 CheckThat! Task 2, which requires ranking reasoning traces generated by large language models (LLMs) to predict a binary verdict for numerical claims in both English and Arabic. Their contribution is an LLM‑based trace ranking system that combines fine‑tuned LLMs with adaptive sub‑claim decomposition or lightweight TF‑IDF reward modeling, and they evaluate these approaches across multilingual data. The work demonstrates that the LLM‑driven method yields higher Recall@5 while handling conflicting claims better than a simple reward model, especially for Arabic where a language‑specific pretrained model outperforms a general multilingual baseline.

**## Key Contributions**  
- **LLM trace ranking with LoRA fine‑tuning**: A lightweight parameter‑efficient fine‑tuning of an LLM to score each reasoning trace as a binary classification problem, enabling precise final verdict selection via Best‑of‑N.  
- **Grouped reward modeling for Arabic**: A TF‑IDF based reward model that aggregates numeric and temporal overlap features per verdict group, showing superior performance on the Conflicting class in Arabic.  
- **Multilingual baseline comparison**: Evaluation against a general multilingual LLM and AraBERT, revealing language‑specific advantages of AraBERT for Arabic claim verification.

**## Methodology**  
The authors first generate reasoning traces from LLMs for each claim. Two experimental pipelines are built: (1) an LLM fine‑tuned with LoRA to output a trace score, then Best‑of‑N selects the top N scores; and (2) a lightweight TF‑IDF reward model that computes numeric and temporal overlap features per trace, aggregates them by verdict group, and outputs a final prediction. For Arabic, both pipelines are evaluated using AraBERT as an alternative to the multilingual LLM baseline. Sub‑claim decomposition is optionally applied to split complex claims into simpler sub‑claims before verification.

**## Results**  
Across all metrics (Recall@5, Precision@5, F1), the LoRA‑fine‑tuned LLM approach achieves the highest Recall@5 and overall F1 scores, especially for English. In Arabic, AraBERT’s grouped reward model outperforms the multilingual baseline on Recall@5 and the Conflicting class, while the LLM pipeline remains competitive but slightly lower. Sub‑claim decomposition did not improve performance; it introduced noise rather than benefit.

**## Significance**  
This work advances automated claim verification by integrating trace ranking with reward modeling, highlighting that fine‑tuned LLMs can surpass simple feature‑based systems when evaluated across languages. The findings guide future research on multilingual reasoning and the trade‑offs between model complexity and performance in low‑resource settings.

**## Related Concepts**
