## Summary  
The paper introduces MedJudgeRAG, a framework that improves medical multiple‑choice question answering by enabling option‑wise evidence judgment using a dynamic knowledge graph derived from retrieved documents. Instead of blindly feeding retrieved text to a language model, the system judges each answer option’s evidential support and then selects a reasoning strategy based on those judgments. This approach leverages structured reasoning traces generated by a teacher LM to fine‑tune the model with a weighted loss that treats the knowledge graph and reasoning components differently. The framework consistently outperforms vanilla RAG and parametric baselines, demonstrating the value of dynamic KG conditioning.  

## Key Contributions  
- [Dynamic Knowledge Graph Construction]: MedJudgeRAG builds a dynamic knowledge graph from retrieved documents, representing entities and relations to capture medical domain facts.  
- [Option‑wise Evidence Judgment]: The model evaluates each answer option’s evidential support separately, producing an evidence verdict that guides downstream reasoning.  
- [Weighted Cross‑Entropy Training with Structured Reasoning Traces]: Training employs a loss function that differentially weights KG conditioning and reasoning segments, using teacher‑generated traces to supervise both components.  

## Methodology  
The authors approached the problem by first retrieving relevant medical documents for each question. These documents were transformed into a knowledge graph where nodes are entities (e.g., diseases, treatments) and edges encode relations (e.g., “treatment causes”). For every MCQ option, the system computes an evidence verdict: whether the retrieved KG supports the option’s claim. The model then selects a reasoning path—either using the KG directly or generating a textual explanation—based on the verdict combination. Training uses supervised fine‑tuning where each training example includes a teacher LM’s structured reasoning trace; the loss weights the KG segment higher to encourage accurate graph construction while still allowing reasoning flexibility.  

## Results  
Experiments were conducted on two medical MCQA benchmarks: MedMCQA and PubMedQA. MedJudgeRAG achieved an average accuracy of 84.2%, compared with 71.5% for vanilla RAG and 73.0% for the best parametric baseline (PubMedQA). Ablation studies showed that using the dynamic KG as graph‑conditioned supervision during training improved performance by 6.3 percentage points over explicit output conditioning, indicating that the KG’s role is most beneficial at training time. The model also reduced average reasoning latency by 12% due to more targeted evidence use.  

## Significance  
This work demonstrates that grounding retrieval in a dynamic knowledge graph can substantially enhance medical MCQA performance beyond simple document concatenation. By treating evidence judgment as an intermediate step, MedJudgeRAG aligns the retrieval process with the model’s reasoning needs, leading to higher accuracy and more efficient inference. The findings suggest that KG‑conditioned supervision is a powerful technique for improving LLM‑based medical QA systems.
