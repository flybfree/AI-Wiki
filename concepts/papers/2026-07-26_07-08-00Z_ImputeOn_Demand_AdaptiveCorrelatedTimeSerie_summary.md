## Summary  
The paper tackles the challenge of imputing missing values in correlated time‑series (CTS) data generated by Internet of Things devices, where existing methods are static and cannot adapt to changing sensor conditions. It introduces **AdaCTSi**, an adaptive CTS imputer that can selectively impute only incomplete sensors while preserving spatial correlations. The model’s design allows a single trained architecture to support both sensor‑subset changes and limited computational resources, making it suitable for deployment on commodity devices such as microcontrollers.

## Key Contributions  
- **Adaptive CTS Imputation Framework**: AdaCTSi combines a One‑shot Temporal Convolutional Network with a learned Time‑Sensor Index Table to extract sensor‑wise embeddings that are independent of the current sensor subset.  
- **Dynamic Spatial Feature Extraction**: Sparse Spatial Attention and Correlation‑Weighted Sensor Selection jointly identify the most informative sensors, enabling efficient extraction of dynamic spatial correlations without over‑fitting to static patterns.  
- **Resource‑Efficient Deployment**: The model’s modest memory footprint permits inference on MCUs, allowing real‑time imputation in resource‑constrained IoT environments.

## Methodology  
AdaCTSi first trains a Temporal Convolutional Network (TCN) using a one‑shot approach that learns a generic encoder capable of handling variable input lengths. A secondary learned Time‑Sensor Index Table maps each sensor’s temporal pattern to an embedding vector, decoupling the representation from the actual sensor IDs present in a batch. During inference, Sparse Spatial Attention dynamically selects which spatial positions (and thus sensors) contribute most to the imputation task, while Correlation‑Weighted Sensor Selection adds weights that prioritize sensors with high correlation strength and low variance. This combination allows the model to adapt to missing or degraded sensors without retraining.

## Results  
Experiments on twelve baseline methods across three adaptability scenarios and five benchmark datasets (traffic flow, air quality, trajectory) demonstrate that AdaCTSi reduces mean absolute error by an average of **33.1 %** relative to the strongest baseline on each dataset. The improvement persists under sensor‑subset changes and limited compute conditions, confirming both accuracy gains and practical adaptability.

## Significance  
By providing a single, lightweight model that can handle arbitrary sensor subsets and limited hardware resources, AdaCTSi addresses longstanding limitations of CTS imputation: static architectures, inability to selectively impute incomplete sensors, and high memory demands. This enables scalable, real‑time inference in diverse IoT deployments, from edge sensors to autonomous vehicles.
