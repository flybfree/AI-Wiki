## Summary  
AnchorFold proposes a training‑free focus‑then‑fold framework for compressing the multi‑vector visual document retrieval index, which stores hundreds of patch embeddings per page. The method first selects high‑centrality tokens as anchors using Recursive Attention Propagation over visual self‑attention graphs and then groups remaining tokens around these anchors in a normalized retrieval space. This two‑stage process concentrates capacity on structurally important regions while preserving non‑anchor contributions, enabling near‑lossless compression without retraining. Experiments show that the approach retains 98 % of full‑index NDCG@5 at 5× compression and 92 % at 20× compression across multiple retrieval backbones.

## Key Contributions  
- AnchorFold introduces a focus‑then‑fold paradigm that separates token selection from centroid aggregation, allowing explicit prioritization of important regions.  
- It employs recursive attention propagation within each attention head and layer to compute centrality scores without any training data, achieving high‑quality compression in a fully offline manner.  
- The framework delivers near‑lossless retrieval quality (98.3 % NDCG@5 at 5×) while reducing storage and scoring overhead up to 20×.

## Methodology  
AnchorFold operates on the visual self‑attention graph generated by a document encoder. Recursive Attention Propagation is run multiple times within each attention head and across all layers, propagating scores step‑wise to capture long‑range dependencies. The focus stage extracts the tokens with the highest centrality as anchors. In the fold stage, the remaining tokens are mapped to their nearest anchor in the normalized retrieval space using cosine similarity. Each anchor‑centered group is then summarized by a centrality‑weighted aggregation, which aggregates token embeddings while preserving the influence of less important regions.

## Results  
Across ViDoRe v1/v2 and REAL-MM‑RAG with three diverse retrieval backbones, AnchorFold outperforms all evaluated training‑free baselines for compression ratios γ ≤ 0.20. On ViDoRe v1/v2 the method maintains 98.3 % of the full‑index NDCG@5 at 5× compression and 92.4 % at 20× compression, demonstrating that substantial storage reduction does not significantly degrade retrieval performance.

## Significance  
Training‑free index compression is critical for large‑scale visual document retrieval where memory and compute are limited. AnchorFold’s focus‑then‑fold strategy reduces the index size dramatically while keeping retrieval quality near that of the original full index, enabling practical deployment in production systems without costly retraining pipelines.
