## Summary  
The paper proposes the Agent‑Native Immune System (ANIS), a biologically inspired defense architecture that is embedded directly within an autonomous agent’s runtime cognitive loop. By integrating Barrier Immunity, a unified taxonomy of threats and vaccines, and a self‑monitoring Harness Triad (Meta, Self, Auto) for continual learning, ANIS aims to protect agents from runtime hijacking that current external defenses cannot prevent. The work also establishes a theoretical boundary between static model alignment and dynamic agent immunity, highlighting the need for new evaluation metrics such as the Autoimmunity Rate.

## Key Contributions  
- [Finding 1] A six‑layer Immune Tower (L0–L5) is introduced, with Layer 1 providing Barrier Immunity—a non‑cognitive, physical‑and‑logical isolation barrier.  
- [Finding 2] A unified taxonomy of Agent Viruses and Agent Vaccines distinguishes superficial, non‑parametric defenses from robust, parametric vaccines that can be updated in real time.  
- [Finding 3] The Harness Triad (Meta, Self, Auto) enables Continual Immune Learning, allowing the system to dynamically adapt vaccines to novel threats.

## Methodology  
The authors designed ANIS as an endogenous defense module that operates inside the agent’s active reasoning pipeline. They first modeled threat vectors as “Agent Viruses” and defenses as “Agent Vaccines,” then built a layered architecture where each layer adds a specific type of protection (e.g., logical isolation, memory sanitization). The Harness Triad was implemented as meta‑monitoring agents that supervise the Self‑learning subsystem, which in turn auto‑generates updated vaccine parameters. This closed‑loop process is formalized to ensure that immunity evolves alongside the agent’s environment.

## Results  
The framework provides a clear theoretical demarcation: model alignment supplies a static constitutional value during training, whereas ANIS acts as dynamic law enforcement at runtime. Simulations show that Barrier Immunity reduces successful memory poisoning attacks by up to 92 %, and Continual Immune Learning lowers the Autoimmunity Rate—false‑positive intervention incidents—to near zero for previously unseen threat patterns.

## Significance  
ANIS bridges a critical gap in AI security by moving defense from pre‑deployment training-time alignment to an active, runtime‑embedded system. This approach mitigates longstanding vulnerabilities such as memory poisoning and multi‑agent protocol attacks, paving the way for truly autonomous agents that can self‑heal against evolving threats.

## Related Concepts  
Immune Tower layers (L0–L5), Barrier Immunity, Agent Virus taxonomy, Agent Vaccine taxonomy, Harness Triad (Meta, Self, Auto), Continual Immune Learning, model alignment vs. agent immunity, Autoimmunity Rate as an evaluation metric.
