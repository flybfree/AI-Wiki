## Summary
This paper addresses the critical challenge of reliably verifying mathematical answers generated by Large Language Models (LLMs), a task where existing methods often fail due to either imprecise natural language reflection or premature coupling of high-level modeling with low-level code execution. The authors introduce Agentic Mathematical Tool-Flow Verification (AMTFV), a novel framework that decouples the logical verification process from concrete computational execution through an innovative interface called Mathematical Tool Flow (MTF). By utilizing this interrupt-execute-resume mechanism, AMTFV allows a verification agent to construct workflows and delegate exact computations to a specialized mathematical toolbox agent, ensuring precision without sacrificing flexibility. The study demonstrates that this approach significantly enhances the self-correction capabilities of LLMs across various complex reasoning tasks.

## Key Contributions
- **Decoupling Verification Logic from Execution**: AMTFV introduces the Mathematical Tool Flow (MTF) interface, which effectively separates the high-level logical planning of verification from the low-level details of code execution, allowing for more robust and modular mathematical reasoning.
- **Enhanced Self-Correction via Exact Computation**: The framework enables LLMs to perform exact computations through a dedicated mathematical toolbox agent, significantly improving the accuracy of candidate answer adjudication and subsequent revision processes compared to traditional natural language reflection methods.
- **Superior Performance on Complex Tasks**: Experimental results indicate that AMTFV outperforms strong baselines across five challenging mathematical reasoning datasets, with particularly notable improvements in handling samples of medium and high verification complexity, achieving up to an 8.3 percentage point increase in accuracy.

## Methodology
The authors propose a multi-agent architecture centered on the Mathematical Tool Flow (MTF) interface. The process begins with a verification agent that analyzes the LLM's candidate answer and constructs a verification workflow. Instead of writing full code or relying solely on text, the agent encodes specific mathematical objects and computational intents into an MTF request. This request is sent to a mathematical toolbox agent, which parses the intent, generates executable calls, and dispatches them to a backend for exact computation. The tool outputs are then fed back to the verification agent to adjudicate the correctness of the original answer, revise it if necessary, or update the verification workflow itself. This iterative loop ensures that logical errors are corrected through precise mathematical evidence rather than heuristic text generation.

## Results
The evaluation was conducted on five challenging mathematical reasoning datasets using seven model configurations from DeepSeek, GPT, and Gemini. AMTFV consistently outperformed representative baselines overall. Notably, under individual model configurations, it improved average accuracy by up to 8.3 percentage points compared to the strongest baseline. The gains were most pronounced in samples requiring medium and high verification complexity, suggesting that the method is particularly effective for difficult problems where simple text-based reflection is insufficient.

## Significance
This work matters because it solves a fundamental bottleneck in LLM reliability: the inability to trust their own outputs without external validation. By decoupling logic from execution, AMTFV provides a scalable and precise method for self-correction, which is essential for deploying LLMs in high-stakes mathematical applications where exactness is non-negotiable.
