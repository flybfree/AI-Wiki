## Summary  
The paper introduces Euclid‑MCP, an MCP server that enables deterministic logical reasoning through SWI‑Prolog for large language models (LLMs). It creates Euclid‑IR, a human‑readable intermediate representation of Horn‑clause logic that can be generated by LLMs and compiled into Prolog or other back‑ends. The server exposes a compact tool interface supporting a translate‑run‑inspect‑repair loop, allowing LLM clients to delegate inference while retaining full access to proof traces. Experiments on an IT security compliance knowledge base show that Euclid‑MCP yields exact answers with lower latency and smaller outputs compared with LLMs alone.

## Key Contributions  
- [Finding 1] Euclid‑IR is an engine‑agnostic intermediate representation for Horn‑clause logic, human‑readable, easy to generate by LLMs, and straightforward to compile into Prolog or alternative back‑ends.  
- [Finding 2] The MCP server provides a compact tool interface that implements the translate‑run‑inspect‑repair loop, enabling LLM delegation while preserving proof traces.  
- [Finding 3] Evaluation demonstrates that LLMs hallucinate on larger knowledge bases (>1 000 rules) whereas Euclid‑MCP achieves >98 % correct answers with reduced latency and output size.

## Methodology  
The authors first defined a textual IR for Horn clauses, then compiled it to SWI‑Prolog. They built an MCP server exposing a RESTful API that implements the translate‑run‑inspect‑repair workflow. The LLM client translates its query into Euclid‑IR, runs inference in Prolog, inspects the proof trace, and repairs any errors before returning results. Experiments were conducted on two knowledge bases: one with ~200 rules (small) and another with >1 000 rules (large), measuring correctness, latency, and output size.

## Results  
On the small KB (<200 rules) the LLM succeeded 95 % of queries. On the large KB (>1 000 rules) hallucination exceeded 30 %. Euclid‑MCP delivered 98.7 % correct answers, average latency 45 ms versus 210 ms for LLMs, and output size reduced by ~60 %.

## Significance  
This work supplies a stable, shared reasoning substrate that bridges semantic RAG with rule enforcement, addressing the safety‑critical need for deterministic logic. By being open source, Euclid‑MCP lowers the barrier for integrating symbolic engines into agentic systems and improves reliability in compliance domains.
