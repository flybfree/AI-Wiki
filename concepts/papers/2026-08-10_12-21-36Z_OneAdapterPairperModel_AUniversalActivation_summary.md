## Summary  
The paper introduces a Universal Activation Bus that enables activation‑based tools to be shared across compatible language models without retraining the entire model. By learning a lightweight encoder‑decoder adapter pair per model and freezing it, the framework creates a common hidden space where semantic neighborhoods are preserved. This allows probes, sparse autoencoders, and natural‑language interpreters originally trained on one model to operate seamlessly on another. The approach demonstrates that activation interfaces can be reused across five models with minimal additional computation.  

## Key Contributions  
- [Finding 1] A shared dense latent space is learned jointly from source models together with a single encoder‑decoder adapter pair per model, establishing a universal activation interface.  
- [Finding 2] The frozen adapter pairs enable downstream tools (e.g., probes and SAE) to be transferred between models without retraining the full network.  
- [Finding 3] An intermediate activation generated by one model can be injected into the frozen upper layers of another model to produce predictions, showing cross‑model inference capability.  

## Methodology  
The authors first train a set of source language models and compute a shared latent representation that will serve as the backbone of the universal interface. For each model they fit a lightweight linear encoder‑decoder pair on unlabeled text that is matched to the corresponding source model, thereby learning a per‑model mapping from its native hidden space into the shared space. After this adaptation phase the interface is frozen; new models join the ecosystem by fitting only their own adapter pair on similarly labeled data. The resulting architecture isolates the heavy computation to the adapters while reusing the common activation bus across all connected models.  

## Results  
Across five distinct language models, semantically related texts form consistent neighborhoods in the shared space, indicating that the universal interface preserves semantic structure. Tools such as probes and sparse autoencoders trained on one model continue to work accurately on others without any retraining. Moreover, an activation produced by Model A can be used by Model B’s frozen upper layers to generate predictions, demonstrating functional interoperability. The overhead of the adapter pairs is negligible—each adds roughly 0.1 % of the total model parameters—making the approach computationally efficient.  

## Significance  
This work establishes a stable, model‑wise activation contract that allows reusable tools across compatible language models, reducing the need to rebuild probes or SAE features for each new architecture. By enabling modular interoperability, it lowers compute and data costs, accelerates research iteration, and fosters ecosystem sharing of pretrained utilities.
