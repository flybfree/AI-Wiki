## Summary  
AgentForge is an immersive, role‑playing platform that lets novice developers experience a four‑role software‑repair workflow where three AI agents handle tasks while each learner assumes one specific responsibility. By embedding role‑based scaffolding and metacognitive prompts, the system makes agent coordination visible and encourages learners to monitor their decisions. The study shows that novices can achieve high task completion rates with this support structure, indicating that immersive role‑playing can bridge the gap between learning how agentic AI works and collaborating effectively with it.

## Key Contributions  
- Finding 1: Participants achieved high task-completion rates with AI-agent support.  
- Finding 2: The Code Reviewer practice required significantly more interaction turns, reroutes, and completion time (p_adj = .004), making it the most challenging.  
- Finding 3: Novices reported significant gains in understanding software repair and agent collaboration (p_adj < .001).  

## Methodology  
The authors designed AgentForge as an immersive, multi‑agent simulation where each novice takes one of four roles—Task Planner, Patch Author, Code Reviewer, or Test Runner—while the remaining three AI agents perform the complementary tasks. Role‑specific scaffolding clarifies responsibilities, and metacognitive prompts make intermediate artifacts and coordination steps visible to learners. This approach aims to teach both the mechanics of software repair and the collaborative dynamics between humans and agentic AI.

## Results  
A study with 37 novice developers demonstrated that task completion rates were high when AgentForge’s support was active. Interaction demands varied across practices; the Code Reviewer role required the most turns, reroutes, and longer completion times (p_adj = .004). Despite these challenges, participants showed statistically significant improvements in their knowledge of software repair and agent collaboration (p_adj < .001).

## Significance  
AgentForge offers a practical pathway for teaching novices how to work with agentic AI while fostering critical evaluation of its outputs. By making the collaborative process transparent through role‑based scaffolding, it addresses the core challenge that beginners face when learning both the technology and the human‑AI interaction patterns.
