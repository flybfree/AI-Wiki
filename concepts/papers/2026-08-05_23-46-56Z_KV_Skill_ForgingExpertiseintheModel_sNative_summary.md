## Summary  
The paper introduces KV‑Skill, a design space for external factorized operators that let a frozen language model store procedural knowledge without altering the backbone or appending to the prompt. It offers two complementary pathways: registration converts an authored text skill into a lightweight operator, and reward learning learns a compact latent operator directly from task outcomes. Both methods keep the model’s native parameters untouched while enabling modular, loadable skills that can be shared across tasks. Experiments on LiveMath demonstrate that KV‑Skill consistently outperforms source‑text prompts, SkillOpt, and SoftSkill, achieving 77.2 % accuracy versus 52.0 % for the latter.

## Key Contributions  
- [Finding 1] KV‑Skill provides an external factorized operator interface that can be loaded independently of the model’s weights, allowing modular skill sharing without retraining.  
- [Finding 2] Text‑derived operators generated by KV‑Skill achieve higher accuracy on LiveMath (77.2 %) than using raw source text (23.4 %), SkillOpt (64.5 %), or SoftSkill.  
- [Finding 3] A shared interface can retain three distinct KV‑Skills simultaneously without measurable forgetting, preserving their benefits across tasks.

## Methodology  
The authors designed a lightweight, prompt‑free mechanism that converts either textual specifications of skills into operator objects (registration) or directly learns compact latent operators from reward signals (reward learning). The operators are injected through a shared interface that adds no new positions to the model’s token sequence. This factorization isolates skill knowledge from the backbone, enabling separate training and deployment while preserving the frozen language model.

## Results  
On LiveMath, KV‑Skill reaches 77.2 % accuracy, outperforming all baseline methods. In a matched reward‑training setting with limited parameter budgets, KV‑Skill wins seven of eight comparisons against soft prefixes, prefix tuning, and LoRA. Post‑hoc analysis shows that text‑derived operators retain their advantage when aligned in one direction per injection layer, whereas random directions lose benefit. The shared interface supports three independent KV‑Skills without detectable forgetting.

## Significance  
KV‑Skill demonstrates that procedural knowledge can be compressed into external operators, enabling efficient, shareable skill storage and deployment. By decoupling skills from the model’s weights, it reduces memory footprint, facilitates rapid prototyping, and allows seamless integration across diverse tasks and backbones—addressing a longstanding challenge in modular AI.
