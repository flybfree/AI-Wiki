## Summary  
The paper tackles the inefficiency of pretrained byte‑level BPE tokenizers when applied to under‑represented languages, where a simple tokenizer swap can dramatically alter token IDs and enlarge model embeddings. It proposes a post‑hoc adaptation strategy that keeps the original vocabulary size while preserving most existing token‑to‑ID mappings as a construction‑time compatibility property. The authors formalize the failure of direct transfer as a “merge ordering problem” caused by non‑reachable BPE nodes and introduce a BPE‑guided insertion mechanism to resolve it. Experiments on Ukrainian adaptations of large language models show substantial compression without breaking model internals.

## Key Contributions  
- [Finding 1] Directly transferring tokens from one tokenizer does not guarantee that the resulting token can be derived through the target’s greedy merge graph, exposing a systematic “merge ordering problem”.  
- [Finding 2] The authors introduce BPE‑guided insertion, which builds each transferred token via a decomposition reachable under the target’s rank‑ordered merging process.  
- [Finding 3] Empirical evaluation demonstrates that Ukrainian models achieve 33.5% and 36.6% token‑count reductions while keeping English/European changes within 0.05%, retaining 78.5%/77.3% of original same‑ID rows, whereas alternative removal methods increase token counts by 0.7–2.2%.

## Methodology  
The pipeline first selects script‑aware rows to limit collateral fragmentation, then reconstructs the target‑script byte‑level prerequisites for each transferred token. Using this prerequisite map, BPE‑guided insertion inserts new tokens only where they can be generated by the target’s greedy merge ranks. The process is constrained by global vocabulary size and frequency thresholds, ensuring that no existing model‑vocabulary entry is broken.

## Results  
Ukrainian adaptations of Nemotron and GPT‑OSS reduce token counts by 33.5% and 36.6%, respectively; English and a four‑language European aggregate show changes ≤0.05%; the same‑ID row retention stays at 78.5%/77.3%. Constraint‑matched removal yields similar Ukrainian compression but raises English/European token counts by 0.7–2.2%. Fresh, same‑size retraining compresses Ukrainian slightly more (≈1 %) but loses all retained same‑ID rows and increases English tokens by 7.6–8.6%; a Cyrillic micro‑aggregate sees 6.7%/10.1% growth. All 28,134 inserted BPE nodes are reachable under ordinary rank ordering, and no original entry is newly broken.

## Significance  
By preserving the model’s vocabulary size and embedding matrices while dramatically reducing token counts for low‑resource languages, this work enables efficient deployment without costly retraining or architectural changes. The approach also provides a principled framework—merge‑ordering analysis and BPE‑guided insertion—that can be applied to any language pair where byte‑level BPE is used.
