# AI/ML Foundations Syllabus



**Source**: [Original Article](https://example.com/placeholder)
A concept-first, math-light syllabus for building a basic understanding of machine learning and artificial intelligence.

Time budget:
- Each lesson is designed to fit within 90 to 180 minutes
- No lesson should exceed 3 hours

Course design principles:
- Use plain language
- Focus on concepts, not formulas
- Build from broad ideas to specific model families
- Tie ideas back to the wiki’s existing AI/ML sources
- Use the Ilya Sutskever reading list as the backbone for sequence models, attention, and generative systems
