# AGENTS.md

**Source**: [AGENTS.md](https://agents.md/)

## Summary
AGENTS.md is a simple open format for giving coding agents project-specific instructions. It acts like a README for agents: a predictable place for build steps, tests, conventions, and other context that helps an agent work safely in a repo.

## Key Takeaways
- Put agent instructions in a predictable place.
- Keep human-facing README files focused on humans.
- Store the extra agent context separately so it stays easy to find.
- Treat project conventions as part of the harness, not an afterthought.

## Why it matters here
AGENTS.md is the repo-level version of harness engineering. It makes the control layer more explicit by telling the agent what rules to follow before it starts acting.
