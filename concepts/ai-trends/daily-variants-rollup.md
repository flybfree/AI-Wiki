# Daily Variants Rollup

**Source**: [AI Research Wiki](https://github.com/flybfree/AI-Wiki/wiki)

## Summary

Recurring AI news feeds generate near-duplicate daily pages. This hub keeps the family-level view: one row per source, the latest raw page, the latest summary page, and a short maintenance note. When a new day lands, update the row instead of creating a new concept page.

## Maintenance Rules

- Keep the day-specific raw pages and summaries as the archive.
- Update the latest links in this table when a new edition arrives.
- If a daily page contains placeholder text or duplicated summary blocks, clean it before linking here.
- Create a new family row only when the source changes substance, not just date.

Use this page as the stable landing zone for daily variants:

1. Keep the raw source page for traceability.

4. If a source starts covering a different topic family, split it into a separate concept page.
