# AI Research Wiki

This repository is the working wiki for AI research curation, article summaries, paper notes, concepts, and navigation pages.

- [Wiki Landing Page](wiki-landing-page.md) — high-level entry point

- [Index](index.md) — broader catalog / archive entry point
- [Wiki Usage Cheat Sheet](concepts/knowledge-management/wiki-usage-cheat-sheet.md) — compact workflow guide
- [SCHEMA](SCHEMA.md) — page-type and structure conventions

## Where to edit

- **Local wiki**: author and revise content here
- **GitHub wiki**: published remote copy
- **Local Logseq brain**: graph/backlink mirror for browsing and retrieval
- **SMB mirror**: backup copy
- **PRISM Logseq mirror**: fast access mirror only

## Page types

- `concepts/` — durable explanations, hubs, and framework notes
- `entities/article/` — source-specific article takeaways with visible source links
- `papers/` — paper notes and analyses
- `summaries/` or `*_summary.md` — derived summary pages
- `comparisons/` — side-by-side comparisons
- `tutorials/` — step-by-step guides
- `raw/` — immutable source captures
- navigation pages — `index.md`, `wiki-landing-page.md`, `wiki-topic-index.md`

## Conventions

- Keep **visible clickable source links** in rendered pages when the content comes from an external article or paper.
- Use `Summary:` titles/H1s for derived summary pages when needed.
- Prefer the original source over mirrors when the source is known.
- Avoid turning the raw query dump back into uncurated lists; use the navigation pages instead.

## Sync flow

1. Write in the local wiki.
2. Sync to the Logseq brain for graph use.
3. Sync to the SMB mirror for backup.
4. Keep the PRISM graph pointed at `file://PRISM/logseq-brain` only.
