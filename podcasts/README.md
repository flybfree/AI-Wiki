# Podcasts

Top-level workspace for podcast production materials.

## Layout

- `podcasts/<YYYY-MM-DD>/scripts/` — source scripts and working drafts
- `podcasts/<YYYY-MM-DD>/shownotes/` — final show notes and revisions
- `podcasts/<YYYY-MM-DD>/media/` — images, audio, and other supporting assets
- `podcasts/<YYYY-MM-DD>/` — day-specific working area

Add new subfolders under a day only when the workflow needs a new artifact type.
