## Summary  
Firefox’s Smart Window is a privacy‑first AI browsing mode that lets users query their own history and open tabs using natural language, pulling relevant pages and images from a personal browsing archive without exposing raw data to external services. The feature runs in an opt‑in beta, lets users choose which large‑language model (Google Gemini 3.1 Flash Lite, OpenAI’s oss‑gpt‑120b, Alibaba Qwen3, or a local model) performs the queries, and includes a new “AI Controls” panel for granular toggling.

## Key Takeaways  
- Smart Window uses natural‑language queries to surface relevant pages and visual previews from a user’s browsing history without sending raw data to external APIs.  
- Users can select which AI model powers the feature—including local models—to uphold digital sovereignty and avoid reliance on cloud services.  
- The beta is opt‑in, with a dedicated “AI Controls” section allowing users to enable, disable, or limit each function.

## Context  
In 2026 the broader AI landscape in browsers is shifting from forced, always‑on assistants toward optional, user‑controlled utilities that respect privacy. Competing search engines and cloud providers are pushing similar models (e.g., Google’s Gemini, OpenAI’s GPT) into browser extensions, creating a market where AI integration is no longer a default but a configurable add‑on.

## Implications  
This approach sets a precedent for browsers to embed AI as optional tools rather than core experiences, encouraging local model adoption and reinforcing user control over data. It could accelerate the move toward “digital sovereignty” in web browsing, influencing how other platforms design their AI features and shaping consumer expectations for privacy‑centric AI integration.
