## Summary
This paper shows that think-aloud traces can materially improve automated cognitive model discovery beyond using behavior alone. In risky decision-making tasks, adding process-level language data improves predictive performance and changes the class of models the system discovers.

## Key Takeaways
- Augments behavioral data with Think Aloud traces during model discovery.
- Improves held-out predictive performance.
- Changes discovered model structure for most participants, from Explicit comparator to Integrated utility.
- Suggests some mechanisms are not recoverable from behavior alone.

## Context
The authors focus on the under-determined nature of cognitive modeling when only behavioral trajectories are available. The work explores whether language explanations can constrain automated discovery in a more informative way.

## Implications
Process data may be a valuable input for automated cognitive science workflows. The result suggests that language traces do not just refine fits; they can alter the inferred mechanistic story itself.
