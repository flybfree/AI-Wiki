Now you can generate, preview, and edit PDFs, Google Docs, Google Sheets, slide decks, Markdown files, TXT files, and code
directly within Google Gemini
. The new file editing capabilities are available starting today for all Gemini users, and while PDF previews/editing works on both the web and mobile, all other file formats are only in the web version for now.
Google added support for
generating and downloading files
in Gemini earlier this year, but now you can tweak those files without leaving the Gemini app. Google says you can expand documents to edit them in full-screen mode and highlight text in files to ask Gemini questions or prompt it to make changes to the file, like highlighting a table and asking Gemini to turn it into a graph.
You could already use Gemini to edit files with its integrations in Google’s Workspace apps, like the
Gemini bar in Google Docs
. Anthropic also launched a feature earlier this year that allows users to
generate and edit documents and presentations
in Claude chats.
