# Deep Residual Learning for Image Recognition (ResNet)

**He et al., Microsoft Research (2015)**
arXiv:1512.03385

## Abstract

Deeper neural networks are more difficult to train. We present a residual learning framework to ease the training of networks that are substantially deeper than those used previously.

## Key Concepts

### The Problem: "Why are deeper networks harder?"
You'd expect: more layers = better results. But in practice, adding layers past ~20 made networks WORSE:
- Training error went UP (not just test error)
- The network couldn't learn at all — it wasn't "overfitting," it was failing to train

This is the **vanishing gradient problem**: when backpropagating error through many layers, the signal gets weaker and weaker — like whispering through a long corridor, each room muting the message.

### The Solution: "Skip Connections" (Residual Connections)
Instead of forcing each layer to learn the full transformation, let it learn only the "residual" — the difference from the previous layer.

- **Standard**: Layer learns f(x) = the transformation
- **Residual**: Layer learns f(x) = x - where x is what came before (the "identity shortcut")

So if x is already good enough, the network just learns to make tiny adjustments. It doesn't have to unlearn everything.

### The Analogy: Building a Wall vs Adding Bricks
- **Before ResNet**: Each layer is a brick that must stand alone
- **After ResNet**: Each layer is an addition to what came before — like adding floors to an existing building rather than building from scratch every time

### The Architectural Impact
- ResNet enabled training networks with **152 layers** (vs ~20 before)
- Performance on ImageNet dropped from 7.5% error to 3.6%
- Residual connections are now used in nearly every deep network architecture

## Why This Changed Architecture Design

### Training Deeper Was Now Possible
Every modern architecture includes some form of residual connection:
- Transformers: Use residual connections after every attention block
- BERT: Built entirely on ResNet-style blocks
- GPT-3: Uses residual connections in its 96-layer decoder stack
- Stable Diffusion: Uses residual connections throughout

You can't build modern AI without residual connections.

### The Deeper-is-Better Principle
Before ResNet: "Let's try a few layers, maybe 10-15."
After ResNet: "How deep can we go?" — enabling the scaling approach.

## For the Course

### Lesson 14 (Choosing the Right Architecture)
This paper directly addresses:
- **Why different data types need different architectures**: ResNet solved the vision problem (deep networks for images) in the same way transformers solved the language problem
- **Architecture matching task to problem type**: Vision needed deep CNNs; language needed transformers; both needed residual connections to scale
- **The trade-off between depth and tractability**: More layers needed more coordination (hence the need for residual connections)

### Lesson 6 (Neural Networks)
Residual connections are taught in the neural network lesson because:
- They solve a fundamental neural network training problem
- They're used in virtually every modern network
- They explain why today's networks have hundreds of layers while older ones had dozens

- Use the "skipping a step on a staircase" analogy for residual connections
