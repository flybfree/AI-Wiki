# Language Models Are Few-Shot Learners (GPT-3)



**Source**: [Original Paper](https://example.com/placeholder)
**Brown et al., OpenAI (2020)**
arXiv:2005.14165

## Abstract

We show that scaling up language models greatly improves task-agnostic, few-shot performance, sometimes even reaching competitiveness with prior state-of-the-art fine-tuning approaches.

Specifically, we train GPT-3, a decoder-only transformer language model with 175 billion parameters, 10x the size of GPT-2, on a corpus of text with 45TB processed during training.

## Key Concepts

### What "Few-Shot" Means
Before GPT-3, the standard approach to NLP tasks was:
1. Pick a task (sentiment, translation, QA)
2. Design a model architecture for that task
3. Train it with labels specific to that task

GPT-3 showed that a single model, trained on raw text, could perform tasks by just "showing it examples in the prompt":

- **Zero-shot**: Give instructions, no examples → "Translate 'hello' to French" → "bonjour"
- **One-shot**: Show one example → "English: hello → French: bonjour. English: goodbye → French: au revoir"
- **Few-shot**: Show multiple examples → the pattern emerges from the prompt

This is a fundamentally different paradigm: **task-specific learning happens at inference time, not training time**.

### The Scaling Insight
The paper empirically demonstrated that:
- Model quality improves smoothly with scale (parameter count, data, compute)
- GPT-3's 175B parameters produced emergent capabilities:
  - Code generation
  - Multi-turn dialogue
  - Few-shot learning for translation, QA, reading comprehension
  - Even some rudimentary reasoning

### The Prompt as Programming Language
GPT-3 showed that:
- The prompt (context at the top of the input) becomes a kind of instruction set
- By putting examples in the prompt, you "program" the model for a new task
- This turned LLMs from passive text generators into task-specific tools

### The Decoder-Only Architecture
GPT-3 uses only the decoder stack from the Transformer (no encoder):
- Autoregressive: predicts the next token
- Trained on prediction, not classification
- At inference, "prompted" with task examples

This is simpler than BERT (which has an encoder) but more general.

## Why This Changed Everything

### The Unified Model Paradigm
Before GPT-3: Different models for different tasks.
After GPT-3: One giant model trained on text, prompted for any task.

### Foundation Models
GPT-3 helped define "foundation models" — models trained on broad data that can be adapted to many downstream tasks without task-specific training.

### The Modern AI Era
GPT-3's demonstration that scaling + text prediction = general capability is what drives every major AI effort since. ChatGPT (GPT-3.5), Claude, GPT-4, Gemini all trace back to this paper.
