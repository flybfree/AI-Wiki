# Denoising Diffusion Probabilistic Models (DDPM)



**Source**: [Original Paper](https://arxiv.org/abs/2006.11239)
**Ho et al., UC Berkeley / OpenAI (2020)**
arXiv:2006.11239

## Abstract

We present high quality image synthesis results using diffusion probabilistic models, a class of latent variable models inspired by considerations from nonequilibrium thermodynamics.

## Key Concepts

### What is a Diffusion Model?
A diffusion model learns to generate data by reversing a noise-adding process:

1. **Forward process**: Start with a real image (e.g., a cat). Add Gaussian noise step-by-step until it becomes pure random noise.
2. **Reverse process**: Learn to reverse this process — start with random noise and progressively remove noise to recover an image.

### The Generative Process
Generation works like sculpting with noise:
- Start with a blank canvas of pure noise
- Apply a learned noise-removal step (like a denoising filter)
- Repeat until a clean image appears
- Each step removes a little more of the "noise mask" to reveal more structure

### The Innovation
Key insight: **Instead of generating an image in one shot (like GANs), generate it step-by-step**.

Each step asks: "Given this noisy image, what would it look like if I removed some noise?"

The model learns to predict what the noise was, then subtracts it. Over many steps (typically 100-1000), the image emerges from the noise like a photograph developing in a darkroom.

### Why Diffusion Works
- **Stability**: Unlike GANs, diffusion models don't suffer from mode collapse (one output repeated)
- **Quality**: The step-by-step process allows fine control over output generation
- **Diversity**: Can generate many different outputs from the same starting noise
- **Training**: Simpler and more stable to train than GANs

### Connection to Transformers
Modern diffusion models (like Stable Diffusion, DALL-E 2) use transformers as the core denoiser network. Attention mechanisms help the model understand which parts of the noisy input should inform which parts of the output.

## Why This Changed Generative AI

### The New Generative Paradigm
Before 2020, GANs dominated generative AI. After DDPM:
- Diffusion models quickly surpassed GANs in image quality
- Stable Diffusion (2022), DALL-E 2 (2022), and Midjourney (launched 2021) all use diffusion
- Text-to-image generation became practical and accessible to everyone

### The "Generative AI = Creation" Model
DDPM democratized image generation:
- Anyone with a text prompt could generate images
- No training required at inference time
- Quality at consumer-accessible scale
