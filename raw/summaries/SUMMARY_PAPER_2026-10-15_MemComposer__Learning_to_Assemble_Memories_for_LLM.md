## Summary
MemComposer introduces a learned memory assembly policy for LLM agents that goes beyond simple semantic similarity retrieval by jointly evaluating the current query against retrieved candidate memories to determine which experiences to include, how many to select, and in what order to present them. The system is trained via Experience Policy Optimization (ExPO), a GRPO-based reinforcement learning framework that uses downstream task-success feedback to optimize the assembly strategy, achieving superior performance over baselines while simultaneously reducing memory-token consumption by up to 16.9%.

## Key Takeaways
- MemComposer reframes memory retrieval as a learned decision-making problem rather than a static similarity search. The composer jointly examines the current query and retrieved candidates to make three critical decisions: which memories to include, how many to select, and how to order them. This addresses a fundamental gap in agent memory systems where semantic similarity alone does not guarantee that retrieved memories will actually improve downstream task performance.
- The training framework, Experience Policy Optimization (ExPO), is built on GRPO (Group Relative Policy Optimization) and evaluates assembled memory contexts through complete agent interactions rather than proxy metrics. This means the policy is optimized end-to-end using actual task-success feedback, ensuring that the learned assembly strategy directly correlates with real agent performance improvements across diverse task domains.
- The learned policy demonstrates strong generalization: it transfers to unseen domains, different frozen executors, and alternative memory banks without retraining. Additionally, it benefits from memories generated by stronger models without requiring further training, suggesting the assembly policy learns transferable principles about what makes memories useful rather than memorizing domain-specific patterns.

## Context
This paper sits at the intersection of agent memory systems, retrieval-augmented generation, and reinforcement learning for language models. As LLM agents increasingly rely on external memory stores to accumulate and reuse past experiences, the field has largely treated memory retrieval as a fixed pipeline where embedding similarity determines what gets presented to the agent. MemComposer challenges this assumption by demonstrating that the selection, quantity, and ordering of memories are themselves learnable policies that can be optimized through downstream task feedback, representing a significant shift from heuristic retrieval to learned, query-adaptive memory composition.

## Implications
For practitioners building agentic systems, MemComposer offers a practical path toward more efficient and effective memory-augmented agents: reducing token usage by 16.9% while improving task performance directly translates to lower inference costs and faster agent responses in production deployments. The transferability of the learned policy across domains, executors, and memory banks suggests that a single well-trained composer could serve as a reusable component in multi-agent architectures, reducing the engineering burden of hand-tuning retrieval strategies for each new application. For the broader research community, the ExPO framework demonstrates that reinforcement learning can be effectively applied to structured decision-making within agent pipelines, opening new directions for optimizing not just what agents generate but what information they are shown.
