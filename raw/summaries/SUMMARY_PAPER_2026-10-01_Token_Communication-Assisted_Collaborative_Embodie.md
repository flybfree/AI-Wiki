## Summary
This paper investigates token communication (TokCom) as a native intelligence interface for collaborative embodied artificial intelligence (CEAI), where tokens function simultaneously as compact semantic carriers for inter-agent messaging and fundamental inference units within generative foundation models. The authors propose a TokCom-assisted CEAI framework driven by a task-adaptive communication protocol that enables agents to distill multimodal observations and intents into efficient tokens, demonstrating through a collaborative object transport case study that this approach significantly reduces payload bit consumption while preserving task efficiency and robustness against noisy channels.

## Key Takeaways
- Token Communication (TokCom) serves as a dual-purpose interface for CEAI agents, where tokens act concurrently as compact semantic carriers for exchanging multimodal observations, task-relevant insights, and intents over long horizons, while also functioning as the fundamental inference units for generative foundation models.
- The proposed framework utilizes a task-adaptive communication protocol comprising a compact codebook, syntax rules, and contextual examples to guide GFM-based transceivers in distilling complex messages into efficient tokens and accurately reconstructing them after wireless transmission.
- A case study on collaborative object transport validates the framework's effectiveness, showing that TokCom substantially reduces source payload bit consumption compared to raw data exchange while maintaining high task efficiency and demonstrating robustness even under noisy channel conditions.

## Context
As embodied AI systems increasingly operate in dynamic, multi-agent environments, the bottleneck of communicating large-scale multimodal data over bandwidth-constrained wireless links remains a critical challenge for scalable collaboration. This work bridges the gap between communication efficiency and generative model inference by rethinking how agents exchange information, positioning tokens not just as data compression tools but as intrinsic components of the AI's reasoning architecture.
