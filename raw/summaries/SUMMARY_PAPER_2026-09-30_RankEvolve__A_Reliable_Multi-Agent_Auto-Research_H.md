## Summary
RankEvolve is an auto-research framework designed to automate the experimental loop for evolving generative ranking models while addressing critical execution accuracy issues common in long-horizon agent runs. The system utilizes an Executable Operating Protocol (EOP) to enforce state machines and composes heterogeneous coding agents like Claude Code and Codex as a meta-meta-harness that reviews and repairs each other's work. Evaluation results demonstrate significant improvements, raising oracle execution accuracy from 45.8% to 62.5%, achieving superior NDCG@10 metrics on MovieLens-20M compared to published anchors, and validating the approach across transfer splits and ablation studies.
