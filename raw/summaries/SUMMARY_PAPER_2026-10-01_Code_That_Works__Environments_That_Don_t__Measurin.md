## Summary
This study investigates the critical gap between functional code generation and accurate environment specification in AI coding agents, revealing that current models frequently produce dependency specifications that are inconsistent, redundant, or incomplete. Using a three-layer framework to assess declared versus runtime dependencies across multiple agents and languages, the research demonstrates that misspecification is a systematic failure driven by training priors rather than model scale, with agreement on identical tasks
