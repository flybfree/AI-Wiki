## Summary
The paper proposes a conceptual framework for building an electronic explanatory dictionary of Tajik using large language models, addressing the lack of comprehensive digital lexicographic resources for low-resource languages. It integrates morphological analysis, lemmatization, semantic clustering, and LLM‑generated entries into a unified system.

## Key Takeaways
- The framework combines classical lexicographic methods with statistical linguistics and generative AI to create a holistic dictionary architecture tailored to Tajik’s agglutinative morphology.
- Subword tokenization is recommended because it handles high morphological variability efficiently, enabling parameter‑efficient fine‑tuning with limited annotated data.
- The system can serve both as a lexical tool and as a core resource for downstream NLP tasks such as translation, summarization, and sentiment analysis.

## Context
This work responds to the growing need for AI models that function effectively on languages with scarce resources. By applying LLMs to low‑resource settings, it demonstrates how generative techniques can complement traditional linguistic research.

## Implications
For computational linguists and developers, the framework offers a scalable method to extend NLP capabilities beyond high‑resource languages. It also provides a practical path for creating multilingual tools that respect cultural and linguistic specificity.
