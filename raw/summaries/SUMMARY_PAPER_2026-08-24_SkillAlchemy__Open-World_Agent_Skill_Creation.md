## Summary
The paper introduces SkillAlchemy, an admission‑centered framework for creating open‑world agent skills from underspecified briefs and source‑access specifications. It improves skill creation pass rates by 19.9 percentage points over no‑skill execution and beats the best automated baseline by 8.6 percentage points, matching human‑curated performance.

## Key Takeaways
- The framework identifies implicit requirements through contrastive evidence, revealing hidden constraints that authors omit in briefs.
- It admits candidate procedures only if evidence supports their scope, ensuring skill generalization and safety.
- The compiled grammar‑guided skill package yields performance comparable to human‑curated skills across 87 tasks.

## Context
Open‑world skill creation addresses a gap where AI agents lack reusable procedural artifacts for novel tasks. By grounding skills in accessible source data, SkillAlchemy reduces reliance on manual curation and enables dynamic adaptation to new domains.

## Implications
This approach enables scalable automation of skill design, lowering development costs and accelerating deployment of specialized agent capabilities across industries.
