## Summary
This paper introduces BlockPython, a platform that bridges the gap between block‑based and Python programming by providing bidirectional translation and guided learning stages. The system continuously gathers process evidence to diagnose difficulties and offers rule‑driven execution with an AI‑assisted learner companion.

## Key Takeaways
- The four‑stage workflow—Task Decomposition, Block‑Based Practice, Code Challenge, Extended Interaction—forces learners to map program structure onto textual Python code.  
- A deterministic rule‑based engine runs the program and evaluates outcomes while a learning assistant interprets collected evidence to generate explanations and prompts.  
- Process evidence such as block artifacts, code versions, run results, support usage, and dialogue is used for continuous feedback and adaptive assistance.

## Context
The shift from visual blocks to text‑based syntax creates a cognitive gap that traditional curricula often ignore. AI‑driven tutoring systems aim to close this gap by providing real‑time diagnostics and personalized guidance, aligning with broader trends in adaptive learning and educational analytics within artificial intelligence research.

## Implications
For educators, BlockPython offers a concrete tool to assess where learners stumble between block and Python representations, enabling targeted interventions. In industry, the platform’s evidence‑driven feedback can inform curriculum design and support automated onboarding of new programmers, fostering smoother transitions into text‑based development workflows.
