## Summary
NarraWorld introduces a structured memory system for LLM agents engaged in long-form writing, framing memory construction as world creation to ensure narrative consistency and coherence. The system utilizes a shared evidence-grounded graph that generates four distinct views—world facts, character beliefs, open developments, and hypothetical branches—while employing hierarchical aggregation to consolidate events into traceable scenes and plotlines. Evaluated across multiple benchmarks, NarraWorld achieves state-of-the-art performance in long-form writing tasks and demonstrates effective transferability to role-playing and general-purpose memory scenarios.
