## Summary
The paper introduces KnowAct-GUIClaw, a framework that unifies cognitive comprehension and operational execution for personal assistants. It solves OpenClaw’s lack of cross‑platform GUI support and self‑evolution by using accumulated interaction memory to improve task decomposition and tool calls. Experiments on Android, iOS, HarmonyOS and Windows show superior efficiency and accuracy.

## Key Takeaways
- The framework integrates a pluggable GUI subagent with an experience‑attributable memory system that stores user profiles and feedback for continuous improvement.
- It enables seamless cross‑platform migration and fast‑path integration by continuously evolving skill libraries based on execution experience.
- Kimi‑2.6 models achieve the best performance at 64.1% on MobileWorld, outperforming Seed‑2.0‑Pro and GPT‑5.5.

## Context
OpenClaw is a state‑of‑the‑art agent framework for task automation but lacks robust GUI interaction across devices. The rise of personal assistants demands agents that can learn from user behavior while adapting to diverse platforms without manual reconfiguration.

## Implications
This work demonstrates that self‑evolving memory and skill libraries can dramatically boost accuracy and adaptability, offering a template for future agentic systems. Practitioners can adopt the Know‑Route‑Act‑Reflect cycle to create assistants that improve autonomously across ecosystems.
