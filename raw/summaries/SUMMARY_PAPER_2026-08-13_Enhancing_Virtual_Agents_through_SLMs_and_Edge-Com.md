## Summary  
This paper investigates how small language models can power the “Think” and “Memory” components of a Cognitive Embodied Agent Architecture when running on edge hardware. Experiments on an NVIDIA Jetson Orin NX using Qwen2.5 variants show that routing accuracy improves, memory‑read latency is acceptable, and overall system performance supports persistent virtual agents in immersive worlds.

## Key Takeaways  
- The integration of SLMs into the Think process enables lightweight reasoning at the edge while preserving contextual awareness.  
- Memory retrieval speed remains within practical limits when using compact language models on Jetson Orin NX hardware.  
- The prototype demonstrates that selective CEAA components can be realized without sacrificing core cognitive functions.

## Context  
Edge computing and generative AI are converging to allow AI agents to operate autonomously in real‑time virtual environments. This work bridges the gap between theoretical architectures and practical deployment by showing how compact models can handle memory‑driven interactions locally.

## Implications  
Practitioners can adopt SLM‑based modules for edge‑deployed virtual agents, reducing bandwidth and latency while maintaining contextual continuity. The approach supports scalable development of immersive experiences without reliance on cloud resources.
