## Summary
This paper introduces a cloud‑based agentic environment built on JupyterHub and Claude Code to support biological database curation, combined with an interactive four‑hour workshop for the Gene Ontology Consortium. The study demonstrates that 37 participants completed training modules progressing from basic tool use to advanced GO‑CAM pathway curation, highlighting the feasibility of scaling agentic AI across distributed scientific communities.

## Key Takeaways
- Access to agents is centralized through a single API gateway, eliminating the need for individual subscriptions or local software installations.  
- Training progresses gradually, moving from fundamental agent interaction to complex biological pathway curation using established GO‑CAM tools.  
- Direct participant experience evaluating agent output is essential for building confidence and competence in distributed curation workflows.

## Context
The rapid advancement of generative AI has created new opportunities for scientific data management but often leaves practitioners without clear pathways to adoption. This work addresses the gap by providing a concrete, low‑barrier framework that integrates agents into existing curation pipelines while offering structured education.

## Implications
Practitioners can leverage this model to democratize access to advanced AI tools, fostering collaborative knowledge creation across institutions. The approach underscores that successful deployment hinges on seamless infrastructure, pedagogical scaffolding, and hands‑on validation of agent performance.
