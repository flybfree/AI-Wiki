## Summary
The paper presents DS@GT’s submission to the eRisk 2026 Task 1 challenge, where a hybrid multi‑agent LLM system screened depression profiles using an open‑source model and algorithmic guidance. The hybrid configuration achieved an ADODL of 0.9063, ranking third among all complete submissions and second overall among the 21 teams, while its per‑persona API cost was roughly one quarter lower than the paid baseline.

## Key Takeaways
- Hybrid Run 3’s ADODL (0.9063) exceeds the paid baseline’s ADODL (0.8841), demonstrating superior performance despite using a weaker open‑source model.
- The hybrid system ranks third among all complete submissions and second overall, placing DS@GT ahead of many competitors in the competition.
- API costs drop to about one quarter of the baseline while maintaining high accuracy, showing cost‑effective scaling.

## Context
This work contributes to the growing trend of using open‑source large language models (LLMs) for sensitive conversational tasks. By integrating structured algorithmic components, the system mitigates the model’s weaker reasoning and instruction‑following abilities, highlighting a viable path toward high‑quality mental health screening without costly proprietary services.

## Implications
The findings suggest that algorithmic supervision can compensate for model limitations, making open‑source LLMs competitive in real‑world applications. For industry practitioners, this lowers barriers to entry and reduces expenses for large‑scale deployment of conversational depression screening tools.
