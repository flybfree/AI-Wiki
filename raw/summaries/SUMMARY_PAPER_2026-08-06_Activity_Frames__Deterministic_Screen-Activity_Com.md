## Summary
The paper introduces a deterministic pipeline that converts raw screen capture streams into typed activity frames for agent memory, eliminating the need for models during compilation. On a single user’s data set of 128,756 frames over 51 days it reduces a day's raw footage to an 86‑fold smaller prompt‑ready block in 68 ms and yields answer accuracy of 98.4% against an oracle, surpassing LLM summaries that reach only 66‑80%. The same tool also measures routine overhead ratio R and recurrence h for cost modeling.

## Key Takeaways
- A zero‑model pipeline segments screen capture into typed activity frames producing byte‑identical, cacheable context blocks that can be fed directly to agents.  
- The compiled block improves question answering accuracy by 32% over LLM summaries while requiring only 68 ms of processing time per day.  
- It quantifies two previously unmeasured parameters: routine overhead ratio R (60‑343×) and recurrence h (9.0% in‑sample, 7.7% out‑of‑sample).

## Context
Current AI agents rely on active memory that must be generated by models from user utterances, incurring high token costs. Passive screen activity offers a richer, deterministic record of human behavior but lacks standardized conversion to usable prompts.

## Implications
This work enables low‑cost, model‑free agent memory that can be integrated into cost‑aware deployment pipelines and provides empirical bounds for routine overhead in large language systems.
