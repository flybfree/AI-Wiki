## Summary
This paper introduces URAI (Universal Robot-Agent Interface), a framework that reimagines code as policy by separating tool creation from execution to improve efficiency and success rates in robot manipulation. URAI employs a programming agent to generate and refine reusable tools based on task intent and feedback, while an execution agent selects and parameterizes these tools within a closed-loop
