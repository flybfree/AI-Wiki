## Summary
The paper challenges the view that state is a language‑specific Afroasiatic construct and instead proposes it as a universal morphosyntactic mechanism. It formalises the state as a set‑valued function over grammatical templates within a computational learning theory framework. The authors demonstrate that this unified model can generate and predict state‑dependent nominal patterns across languages.

## Key Takeaways
- The state is treated as a set‑valued function applied to each grammatical template, allowing it to vary per context.
- A finite‑set algorithm learns these functions from data, producing predictions of state‑conditioned configurations.
- The framework extends beyond nominal morphology to explain determiner‑noun structure and other syntactically conditioned dependencies.
