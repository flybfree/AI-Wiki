## Summary
Vestrum is a framework designed to optimize agent harnesses by automatically generating scoped modifications based on execution trace failures without requiring task model training. By classifying recurring failure patterns and proposing targeted changes across verification, retrieval, decomposition, and memory synthesis, the system iteratively refines harness performance using a persistent lessons file
