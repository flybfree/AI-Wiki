## Summary
The paper introduces Mawqif-v2 Extension, a new Arabic benchmark dataset for cross-target stance detection. It contains 996 manually curated tweets from three public targets—Women Driving, E‑Cars, and Trimester System—each annotated with stance, sentiment, and sarcasm labels following the original Mawqif scheme. The extension serves as a held‑out set to evaluate model generalization beyond the original Mawqif dataset.

## Key Takeaways
- The dataset includes 996 manually curated Arabic tweets covering three distinct public targets, providing a rich variety for evaluating cross-target performance.  
- Each tweet is annotated with stance, sentiment, and sarcasm labels following the original Mawqif scheme, enabling comprehensive evaluation of model understanding.  
- Baseline results are reported using Arabic multilingual transformers and zero‑shot LLMs to ensure reproducible comparison.

## Context
Cross‑target generalization remains a challenge in NLP benchmarks, especially for low‑resource languages like Arabic. This dataset addresses that gap by offering a dedicated held‑out set alongside the original Mawqif collection, supporting fair evaluation of model adaptability.

## Implications
For practitioners, Mawqif‑v2 enables systematic testing of stance detection models across diverse social media topics, informing design choices for multilingual systems. The benchmark also guides future research toward robust, zero‑shot capable models in Arabic NLP.
