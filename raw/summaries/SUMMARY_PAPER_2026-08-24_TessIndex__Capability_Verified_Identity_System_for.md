## Summary
The paper introduces TessIndex, a capability‑verified identity system for autonomous agents that addresses three gaps in the current agent economy. It combines blockchain commitments with centralized metadata to provide persistent identities and cryptographic proof of capabilities.

## Key Takeaways
- Persistent identities across agent primitives enforce systemic accountability.
- Verification uses predicate‑based cryptographic proofs instead of self‑declaration.
- Value is tokenized by linking performance to both creator and project identities.

## Context
In AI, the rise of autonomous agents creates a new economic model where software entities generate value without human oversight. Existing registries only provide names, lacking verification and persistent identity links.

## Implications
TessIndex enables trustworthy marketplaces for agentic services by proving capability execution and linking reputation to tangible asset value.
