## Summary
This paper introduces Khora, a scalable multi‑agent world model that enables inference‑time expansion to any number of agents without retraining. By decoupling world‑state evolution from visual rendering and using a unified rendering interface, the system maintains cross‑view consistency while supporting arbitrary agent populations. Experiments show linear practical scaling with the number of queried views and consistent visual quality across unseen agent counts.

## Key Takeaways
- The model treats the shared world state as the source of truth, so agents are generated by querying this state rather than being hard‑coded in the video generator.  
- Rendering is population‑agnostic: each new view simply asks the same state for its representation, allowing linear scaling with added agents.  
- The architecture separates world evolution from rendering, preserving cross‑view consistency without dense agent interactions inside the expensive generator.

## Context
Current AI research focuses on single‑agent or fixed‑population world models that struggle to handle dynamic populations at inference time. Scalability remains a bottleneck for open‑world simulation and multi‑agent interaction tasks.

## Implications
Khora’s design opens the door to real‑time, open‑world simulations where agents can appear or disappear without retraining the model. Practitioners in gaming, robotics, and AI research can leverage this framework to build flexible, scalable environments that adapt to varying agent counts on demand.
