## Summary
The paper introduces an autonomous AI agent that designs machine‑learning models for wireless power control without human intervention. Over 81 unattended experiments the agent achieves near‑optimal cell‑edge throughput with far fewer inference passes than manual tuning.

## Key Takeaways
- The agent autonomously selects architecture, loss function and input representation to solve a non‑convex NP‑hard problem of sum‑least‑percentile power control across multicell networks.
- It reaches 99.5 % of the reference solution in one fixed‑cost inference pass while reducing inference cost by roughly 600× compared with human‑tuned methods.
- The discovered output parameterization reproduces exact max‑min optimal allocation for every percentile, showing provable structure rather than merely tuned constants.

## Context
Autonomous agents that generate code and optimize models are reshaping AI research, allowing systems to explore solution spaces without predefined loss functions or architectures. This work demonstrates that such agents can handle highly challenging combinatorial optimization tasks in wireless resource management.

## Implications
For industry, the approach lowers development time and cost for network optimization tools, enabling rapid deployment of adaptive power‑control solutions. Practitioners can rely on provable optimal allocations generated by AI, reducing manual tuning effort and improving reliability across varying network sizes and percentile targets.
