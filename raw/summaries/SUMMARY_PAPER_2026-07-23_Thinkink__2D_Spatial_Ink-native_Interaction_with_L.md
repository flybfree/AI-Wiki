## Summary
Thinkink is a tool that lets users write and draw on a shared canvas while large language models generate ink‑like responses that are spatially integrated with the user’s input. The study combines formative, diagnostic, and final experiments to evaluate usability and human‑LLM interaction.

## Key Takeaways
- The tool visualizes LLM outputs as ink‑like text and sketches that are placed on the same canvas as user handwritten notes, creating a seamless spatial integration of language and drawing.  
- A semantic tree parses these mixed inputs to guide interpretation, ensuring that both textual and graphical elements contribute meaningfully to the ideation process.  
- The lightweight UI employs a state‑machine interface that gives users explicit control over adding, modifying, or removing ink elements during interaction.

## Context
This work addresses the gap between purely text‑based LLM interfaces and multimodal human‑centered design, showing how spatial representation can enhance ideation. It highlights the need for tools that blend language generation with visual expression in creative workflows.

## Implications
For practitioners, Thinkink demonstrates that integrating LLMs with handwritten and sketch‑based ideation can unlock richer mental models and reduce cognitive load. Industries relying on rapid brainstorming may adopt similar multimodal interfaces to boost creativity and collaboration.
