## Summary
This paper demonstrates that interpretable zero‑shot classification can be achieved by selecting visual attributes from the target images rather than relying on class‑name descriptors generated by language models. The authors show that image‑conditioned attribute prompts improve ImageNet accuracy to 23.8% compared with 15.5% for LLM‑generated descriptors, and this gain persists across four shifted variants of ImageNet.

## Key Takeaways
- Removing class names from the prompt collapses ImageNet accuracy from 59.5% to 15.5%, indicating that LLM descriptors are label‑conditioned rather than image‑conditioned.
- Selecting attributes by scoring a pool against CLIP embeddings yields attribute prompts that outperform both LLM descriptors and CoOp, reaching 23.8% accuracy with minimal computation time.
- The attribute set chosen from the data serves as a readable summary of the dataset’s distribution, effectively highlighting shift when comparing variants.

## Context
Interpretable AI models aim to make predictions transparent without hidden parameters, yet many zero‑shot methods depend on opaque language prompts that ignore visual evidence. This work shifts focus to data‑driven attribute selection, aligning model behavior with the actual image content and enabling clearer diagnostics of distribution changes.

## Implications
Practitioners can adopt this approach to build more reliable, explainable vision‑language systems without costly fine‑tuning or soft prompts. By grounding attributes in the dataset itself, models become less sensitive to label noise, offering a scalable path toward trustworthy AI deployments.
