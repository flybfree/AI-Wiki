## Summary
This paper proposes Behaviorally Adaptive Visual Diversion (BAVD) as a theoretical framework that modifies only the visual presentation of assessment content to thwart unauthorized screen capture while preserving its integrity. The framework combines a dynamical‑systems model with an accessibility‑aware attenuation mechanism, achieving closed‑loop adaptation and bounded entropy.

## Key Takeaways
- BAVD creates a synthetic non‑semantic visual field that is composited with the test material without altering any underlying content, thereby reducing the usefulness of screen capture.  
- The system includes an accessibility‑aware attenuation mode that lowers diversion intensity for candidates who have approved visual‑processing accommodations.  
- Theoretical analysis demonstrates bounded entropy and closed‑loop stability, ensuring that adaptation remains secure yet minimally intrusive.

## Context
In high‑stakes digital assessment environments, institutions increasingly deploy browser lockdowns and behavioral analytics, but these measures often ignore learner accessibility needs. This work bridges the gap by embedding accessibility considerations directly into a security‑focused visual diversion strategy, offering a mathematically rigorous alternative to piecemeal solutions.

## Implications
For AI researchers, BAVD provides a principled model that can be integrated into adaptive testing platforms, supporting both security and inclusivity. Practitioners may adopt this framework to design assessments that protect integrity while respecting diverse cognitive needs, fostering trust in automated evaluation systems.
