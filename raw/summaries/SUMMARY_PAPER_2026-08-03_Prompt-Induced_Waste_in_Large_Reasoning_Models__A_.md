## Summary
This paper investigates how the wording of prompts influences the computational waste generated by large reasoning models when used as coding agents, using a preregistered benchmark with six models and two harnesses across 24 tasks. The results show that certain prompt instructions dramatically increase token usage without improving task success rates.

## Key Takeaways
- Prompt formulation can multiply reasoning cost by up to 7.4× across all models when asking the model to develop and compare several approaches.
- Generic “think deeply” cues raise deliberation tokens by a factor of 1.6–2.2, indicating that vague prompting is inefficient.
- A bounded‑efficiency template that specifies scope, acceptance criteria, and a stop condition reduces reasoning cost roughly in half while keeping performance stable.

## Context
Large reasoning models are increasingly deployed as coding assistants, where each token processed incurs real monetary expense. Understanding which prompts drive unnecessary compute helps researchers and developers balance accuracy with resource usage.

## Implications
For practitioners designing prompting strategies, the choice of instruction matters more than model architecture; poorly worded cues can inflate costs without benefit. Similarly, harness selection influences per‑success cost, suggesting that system design should be optimized alongside prompt engineering to achieve true efficiency.
