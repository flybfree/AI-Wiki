## Summary
This paper proposes a finetuned LLM framework that converts unstructured textual resources into structured event logs for process mining, showing that fine‑tuning yields far better results than few‑shot or zero‑shot prompting. The authors demonstrate high‑fidelity log extraction from incident tickets and manuals, establishing finetuning as essential for reliable automated data translation.

## Key Takeaways
- Fine‑tuned LLMs outperform few‑shot or zero‑shot prompting in generating accurate event logs from unstructured text.
- The framework creates a scalable pipeline that bridges textual knowledge bases with the structured event data required by process mining.
- Event logs derived from fine‑tuned models preserve high fidelity, enabling deeper operational analysis.

## Context
Process mining relies on structured event logs to uncover workflow insights, yet these logs are often labor‑intensive to produce. AI research is increasingly focused on automating such translation tasks using large language models, making this work a key contribution to the field’s goal of turning existing textual knowledge into actionable data.

## Implications
Organizations can now leverage vast amounts of unstructured text—such as incident reports and manuals—to generate event logs without costly expert effort. This expands process mining’s applicability, allowing practitioners to explore hidden workflow inefficiencies and improve organizational performance.
