## Summary
The paper addresses the challenge of on‑policy distillation (OPD) when a teacher and the supervised fine‑tuning (SFT) reference are generated by different models, which often leads to wasted performance gains. Lightning OPD 2.0 proposes cross‑fitted style residualization that estimates a recurring style bias between the two sources and removes it before applying token‑level updates. Experiments on mathematical reasoning and code generation show consistent improvements over vanilla Lightning OPD in cross‑teacher settings. Starting from Klear‑Reasoner‑8B‑SFT, the method reaches 82.4% on AIME 2024 and 63.0% on LiveCodeBench v5.

## Key Takeaways
- Raw teacher–reference disagreement contains useful context‑specific evidence that can be leveraged as a proxy for style‑token bias.  
- The method uses rollout‑level cross‑fitting to estimate this recurring component and subtracts it before constructing the OPD update, effectively mitigating style mismatch.  
- Lightning OPD 2.0 consistently outperforms standard Lightning OPD when teacher consistency is not enforced.

## Context
In large language model training, on‑policy distillation offers a way to inject dense token supervision without retraining the entire model. However, real‑world pipelines often involve separate SFT and distillation models, breaking the ideal consistency assumption. This paper contributes a practical solution that relaxes this assumption, enabling flexible pipeline design.

## Implications
For practitioners, Lightning OPD 2.0 allows independent selection of SFT generators and distillation teachers without sacrificing performance, streamlining model deployment. The approach could be adopted across industries to improve reasoning and code generation models while reducing computational overhead.
