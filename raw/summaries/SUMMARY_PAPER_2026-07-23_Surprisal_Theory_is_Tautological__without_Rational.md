## Summary
The paper challenges the claim that human processing difficulty follows a linear relation to surprisal under some language model. It shows this relationship is always possible by constructing a suitable model, making the theory unfalsifiable without further constraints. The authors conclude that existing psycholinguistic work has hidden an empirical assumption that cannot be justified.

## Key Takeaways
- Any non‑negative difficulty pattern can be matched by some language model via an affine transformation, so surprisal theory provides no independent test.
- The tautology arises because the model is assumed to be the corpus distribution, which improves fit but not necessarily predictions of processing difficulty.
- A rationalist intervention is needed: the model must derive from a non‑empirical source such as memory limits or processing goals.

## Context
This work addresses a longstanding assumption in psycholinguistics that language models are purely data‑driven. In AI, it highlights how empirical fits can mask theoretical vacuity and suggests that meaningful models require principled priors rather than fitting only training data.

## Implications
For practitioners, the paper warns against treating model performance as sufficient evidence for human processing mechanisms. It pushes researchers toward integrating cognitive constraints into generative models to generate testable predictions beyond statistical correlation.
