## Summary
Stashbird presents a speaker-indexed memory architecture for conversational agents that establishes explicit provenance between source episodes and derived memory states, facilitating precise updates and deletions across individual and group interactions. The system structures data into episodic records, semantic relations, community summaries, and a persisted graph
