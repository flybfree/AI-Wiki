## Summary
The paper surveys graph-based personalized memory for LLM agents, organizing research into representation, evolution, retrieval, and evaluation. It highlights that structured relational models enable adaptive long-term personalization but current work is fragmented across agents and generic frameworks, making the design space unclear.

## Key Takeaways
- Graph-based personalized memory provides a structured way to model user information through explicit relations, temporal context, and evidence links.
- Existing work remains fragmented across different LLM agents and generic graph memory frameworks, making the overall design space difficult to understand.
- The survey aims to clarify how these representations can support adaptive, controllable, and user-centric LLM agents.

## Context
As LLMs become personal assistants, the need for persistent, adaptable memory grows beyond simple key-value stores to structured relational graphs that capture evolving user preferences. This lifecycle-oriented survey helps researchers navigate the fragmented landscape.

## Implications
This work guides developers in integrating relational memory into agent design, improving consistency and personalization across sessions. It also sets a benchmark for evaluating long-term memory reliability, encouraging reproducible research.
