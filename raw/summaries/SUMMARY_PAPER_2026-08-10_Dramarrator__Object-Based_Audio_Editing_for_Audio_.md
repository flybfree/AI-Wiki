## Summary
The paper introduces Dramarrator, an object‑based audio editing tool for creating audio dramas from books. It extracts story elements as editable objects, generates linked audio assets, and composes a multi‑track drama where changes propagate automatically. User studies show reduced task load and comparable quality to professional tools.

## Key Takeaways
- Dramarrator represents story elements such as characters and scenes as separate object‑based entities that can be edited independently.
- The tool links generated audio assets (speech, sound effects, music) to these objects so modifications automatically update all dependent tracks.
- User study with eight professionals found a significant reduction in task load when using Dramarrator compared with manual assembly.

## Context
Audio drama production traditionally relies on linear editing where each change must be manually propagated across multiple assets, creating bottlenecks. This paper contributes to the growing AI‑driven authoring pipeline by automating extraction and linking of narrative elements, reducing dependency on human labor for asset management.

## Implications
For creators, Dramarrator lowers entry barriers and enables rapid iteration without sacrificing quality, potentially expanding audience reach. For industry standards, it demonstrates that object‑based workflows can be as effective as traditional linear editing, encouraging broader adoption of modular audio production pipelines.
