## Summary
This paper investigates how plugins in Claude Code marketplaces are maintained and evolve over time, using a dataset of 1,926 repositories and 77,773 commits. The study shows that plugin activity surged eightfold after the October 2025 launch, that most plugins address software engineering tasks, and that development is driven by features rather than routine maintenance.

## Key Takeaways
- Plugin‑touching commit activity grew 8.8 times within six months, indicating rapid adoption and ongoing interaction with the marketplace.
- Over 61% of all plugins target software engineering tasks, showing a strong focus on practical coding assistance.
- Natural‑language instruction files and implementation scripts co‑evolve at above‑chance rates, creating functional dependencies that are not typical in conventional open‑source code.

## Context
The rapid growth of AI coding assistants like Claude Code has led to an explosion of plugin repositories that act as extensions for the agents. Understanding how these plugins are sustained is crucial because their maintenance patterns differ from traditional software engineering practices and can affect reliability, scalability, and developer trust.

## Implications
For developers, this suggests that relying on a single plugin may require continuous updates rather than treating it as a static tool. For platform designers, recognizing the co‑evolution of instruction files and scripts opens opportunities to create more resilient marketplace ecosystems. The findings highlight the need for maintenance strategies tailored to AI‑driven development workflows.
