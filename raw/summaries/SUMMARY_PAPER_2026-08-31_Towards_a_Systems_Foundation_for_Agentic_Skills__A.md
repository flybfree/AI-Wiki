## Summary
The paper proposes a unified systems foundation and reference architecture for agentic skills to address reliability bottlenecks in autonomous LLM agents on long tasks. It formalizes skills as externalized procedural knowledge that bridge cognitive planning with deterministic execution environments. The framework outlines nine lifecycle stages from discovery to security governance.

## Key Takeaways
- Skills are modular procedural abstractions that externalize execution knowledge into reusable artifacts, enabling scalability beyond monolithic prompt engineering.
- The architecture spans a nine-stage lifecycle covering autonomous discovery, authoring, memory storage, retrieval, composition, execution, adaptation, evaluation, and security governance.
- The paper identifies marketplace dynamics, public registries, adversarial threats, runtime verification, and defense mechanisms as key components of the ecosystem.

## Context
Autonomous LLM agents face reliability issues when handling complex tasks that require long-term memory and precise tool use. Current monolithic approaches cannot scale, prompting a shift toward modular skill-based designs. This work aligns with broader trends in AI system engineering focusing on verifiable, composable components.

## Implications
For practitioners, the framework provides a concrete blueprint for building robust agents across domains such as software engineering, robotics, and scientific discovery. It also sets standards for security governance and lifelong adaptation, which are critical as agentic skills become standard practice in industry.
