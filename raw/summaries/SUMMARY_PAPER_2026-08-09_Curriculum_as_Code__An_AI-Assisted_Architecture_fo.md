## Summary
This paper introduces a six‑phase AI‑assisted instructional design architecture called “Curriculum as Code” that uses generative AI together with LaTeX and Python to create reproducible STEM teaching materials. The framework cuts faculty preparation time while guaranteeing mathematical precision, visual consistency, and the preservation of pedagogical expertise through explicit rules.

## Key Takeaways
- The system automates slide generation in Beamer by feeding textual prompts into a LaTeX pipeline, eliminating manual formatting errors and ensuring each module follows the same style guide.  
- Python scripts produce high‑resolution figures that are mathematically accurate and linked directly to the LaTeX source, preventing hallucinated or inconsistent visuals.  
- A peer‑review loop and automated checks validate output across 28 project contexts, demonstrating scalability beyond a single author.

## Context
Current AI tools for education often generate content that lacks rigor, leading to hallucinations and misaligned pedagogy. Faculty must manually craft each lesson, which is time‑consuming and error‑prone. This work addresses those gaps by embedding formal constraints into the generation process, aligning with best practices in STEM teaching.

## Implications
Instructors can focus on content rather than formatting, freeing up hours for active learning design. The reproducible codebase enables rapid iteration across courses, supporting institutional scalability and consistent quality standards.
