## Summary
This paper introduces RIDGE, an autonomous framework that validates and refines option pricing implementations generated by large language models. The framework applies structured tests such as no‑arbitrage checks, stress scenarios, benchmark comparisons, and consistency analyses to detect implementation defects. In experiments on five stochastic volatility models, all identified issues were resolved, and the validation process itself uncovered two new semi‑analytic pricing methods.

## Key Takeaways
- RIDGE combines automated code generation with systematic no‑arbitrage and stress testing, producing a diagnostic workflow that pinpoints both coding errors and mathematical inconsistencies.  
- The framework’s repository accumulates validated knowledge across models, enabling reuse and iterative improvement of both implementations and validation methods.  
- Validation not only eliminates defects but also generates novel semi‑analytic pricing approaches, demonstrating the value of feedback loops between implementation and theory.

## Context
The rapid adoption of large language models for quantitative finance creates a need for reliable, mathematically sound code without extensive manual testing. Traditional software verification tools are insufficient for complex financial algorithms that involve stochastic volatility and high dimensionality. This work bridges that gap by embedding validation directly into the generation pipeline.

## Implications
For practitioners, RIDGE reduces risk associated with model‑driven option pricing by providing a reproducible, automated quality check. It also offers a scalable way to share validated code snippets across the community, accelerating innovation in AI‑generated financial algorithms.
