## Summary
The paper introduces the concept of code as agent harness, framing code as the infrastructure that enables agents to reason, act, and model environments. It surveys three layers: interface, mechanisms, and scaling, highlighting methods across various applications. The authors propose a unified roadmap for building executable, verifiable AI agents.

## Key Takeaways
- Code serves as an operational substrate for agent reasoning, action, environment modeling, and execution‑based verification beyond being merely output.
- Harness mechanisms include planning, memory, tool use, feedback‑driven control, and optimization to achieve reliable long‑horizon execution.
- Scaling the harness involves shared code artifacts that support multi‑agent coordination, review, and verification.

## Context
This work addresses a growing shift where AI agents rely on code not only as output but as core infrastructure. It builds on advances in large language models for coding while moving toward autonomous systems that need persistent state and tool integration.

## Implications
For practitioners, the framework offers practical guidance for designing agentic workflows across domains such as DevOps, personalization, and scientific discovery. The emphasis on verification and shared code artifacts can improve safety and scalability of AI agents in real‑world settings.
