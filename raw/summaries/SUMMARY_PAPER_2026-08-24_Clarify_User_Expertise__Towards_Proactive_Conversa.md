## Summary
The paper introduces PASSING, a method for proactive clarification of user expertise to tailor conversational agent responses. It demonstrates that current agents cannot infer expertise from queries alone and that PASSING improves comprehension through targeted What‑to‑ask and How‑to‑ask strategies generated by LLM self‑play.

## Key Takeaways
- Existing conversational agents lack mechanisms to determine user expertise directly from query text, limiting adaptive response generation.  
- The proposed PASSING framework uses What‑to‑ask and How‑to‑ask strategies generated by LLM self‑play to elicit expert‑level clarification.  
- Experiments demonstrate that PASSING outperforms baseline approaches in aligning responses with the inferred expertise level.

## Context
In AI chatbots, personalization is essential for effective information delivery. Current systems focus on interpreting queries but often overlook the user's domain knowledge, leading to mismatched explanations. This paper addresses that gap by focusing on expertise inference as a key component of human‑centric design.

## Implications
The findings suggest that future conversational agents should embed proactive expertise clarification to enhance relevance and reduce cognitive load for users. Practitioners can implement PASSING‑inspired strategies to improve user satisfaction and system performance across diverse domains.
