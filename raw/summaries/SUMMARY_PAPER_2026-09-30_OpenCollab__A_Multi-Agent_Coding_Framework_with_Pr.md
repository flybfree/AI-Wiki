## Summary
The paper introduces OpenCollab, a multi-agent coding framework designed to address the behavioral gap between declared organizational structures and actual agent interactions in complex software engineering tasks. By providing a unified infrastructure for programmable collaboration and controllable runtime with fine-grained event tracking, the authors define an "Adherence" metric to quantify how faithfully agents follow specified workflows. Experiments demonstrate that adherence varies significantly across configurations (47.2% to 97.2%), yet a well-designed two-coder workflow on OpenCollab achieves state-of-the-art performance against mainstream harnesses while maintaining high token efficiency in single-agent modes.

## Key Takeaways
- **Behavioral Gap and Adherence Metric:** Existing evaluations often assume agents strictly follow configured organizations, but reality differs; OpenCollab addresses this by tracking execution via fine-grained event streams
