## Summary
The paper introduces a new version of the Triangolazioni web application that integrates large language models to provide context‑dependent cultural heritage information. It demonstrates how LLMs can be used without tightly coupling the system architecture, enabling flexible retrieval and presentation of external knowledge. The results show improved relevance and user satisfaction compared with static curated content.

## Key Takeaways
- The system decouples LLM usage from the application core, allowing any model to be plugged in while preserving existing data pipelines.
- Context‑aware search is achieved by feeding the current page’s metadata into the LLM, which then generates tailored snippets of external information.
- Evaluation indicates a measurable increase in user engagement and relevance scores when contextual LLMs replace static annotations.

## Context
This work aligns with broader AI research on embedding knowledge retrieval within cultural heritage platforms, where large language models act as dynamic interpreters rather than mere search engines. It highlights the potential for AI to augment human‑curated content without replacing it, a trend seen in many domain‑specific applications.

## Implications
For heritage institutions, this approach reduces manual annotation effort and enables continuous updates through model fine‑tuning. Practitioners can adopt the loosely‑coupled design to experiment with different LLMs, fostering innovation while maintaining data sovereignty.
