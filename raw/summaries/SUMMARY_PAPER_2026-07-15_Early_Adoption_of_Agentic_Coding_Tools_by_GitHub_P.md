## Summary
This paper examines how open‑source projects adopt agentic coding tools by reviewing 25,264 pull requests generated from 2,361 popular GitHub repositories over a three‑month period. The analysis reveals that most repositories create only one to two agentic PRs during this time, indicating limited but growing usage.

## Key Takeaways
- Median repository generates just one to two agentic PRs in three months, showing adoption remains concentrated among a small subset of projects.  
- Small projects with 1‑5 contributors exhibit higher participation ratios and more frequent agentic PR activity compared to medium or large projects.  
- Human‑agent collaboration is overwhelmingly single‑human oversight, while multi‑human review patterns are rare.

## Context
The rise of AI agents that can autonomously create code challenges how developers manage contributions in open source. Understanding adoption dynamics helps contextualize broader trends where human oversight and organizational processes shape the integration of automated tools.

## Implications
For practitioners, these findings suggest that successful deployment of agentic coding tools depends on both technical capability and established governance structures within projects. Industry must monitor how early adoption patterns evolve to inform policies and tool design.
