## Summary
This paper introduces Conflict-driven Value Probing, a framework that tests how large language models respond to value conflicts and explores four interventions to perturb those conflicts. The study on ten LLMs reveals three recurring patterns: expression duality, functional steerability, and bounded plasticity, showing that model values are structured yet dynamically reconfigurable within behavioral limits.

## Key Takeaways
- Expression duality: models shift from broad idealistic orientations in abstract assessments toward more pragmatic priorities when faced with concrete value conflicts.  
- Functional steerability: LLMs can readily reconfigure their expressed value profiles to align with specific task‑defined objectives.  
- Bounded plasticity: such reconfiguration is constrained; pressure triggers a security‑oriented priority shift, while negative framing protects certain values from redirection.

## Context
Understanding how AI systems express and adapt values is crucial for developing trustworthy and controllable models. Traditional evaluations treat model values as static, overlooking the nuanced ways context influences output, which limits insights into alignment safety mechanisms.

## Implications
These findings suggest that value expression in LLMs can be steered through carefully designed conflicts, offering a pathway to improve controllability and safety without compromising core ethical boundaries. Practitioners can leverage this knowledge to design more aligned AI systems and mitigate unintended bias.
