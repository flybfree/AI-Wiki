## Summary
Skill2Env addresses the scalability challenges in constructing executable environments for agent post-training by introducing a capability-oriented framework that synthesizes tasks directly from reusable skills based on specific agent capability demands. The method employs difficulty patterns to generate comprehensive task blueprints and utilizes an Iterative Task Hardening process to refine environments, ensuring sufficient rigor through solver execution feedback. Fine-tuning agents with 1.5K trajectories generated by this approach yields consistent performance gains across diverse benchmarks, confirming the value of automated environment synthesis for enhancing agent capabilities.

## Key Takeaways
- Skill2Env bridges the gap between abstract skills and concrete executable environments by using capability demands to guide task synthesis, creating reusable difficulty patterns that instantiate detailed blueprints specifying objectives, challenges, environment facts, information boundaries, and acceptance criteria.
- The framework features an Iterative Task Hardening mechanism that leverages solver execution evidence to identify insufficiently challenging tasks, subsequently strengthening difficulty patterns, revising blueprints, and updating environments to guarantee high-quality training data.
- Supervised fine-tuning on 1.5K high-scoring trajectories produced by Skill2Env demonstrates consistent improvements across a wide range of agent benchmarks, validating that capability-oriented environment synthesis effectively boosts general agent performance in tool use and multi-step interactions.
