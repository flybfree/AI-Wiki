## Summary
This paper proposes a cognitive capability profiling framework that links AI systems and workplace tasks to a shared set of core mental abilities. By measuring agents on benchmark tests and weighting those capabilities according to expert assessments, the authors create an updatable suitability score for any domain or role.

## Key Takeaways
- The pipeline uses a common cognitive dimension set to infer agent strengths and task demands, allowing independent updates as models or roles evolve.  
- AI systems varied more across these dimensions than within model families, indicating that capability differences are not just technical but also contextual.  
- Task requirements from 410 employees across six occupations converged on a shared cognitive core, revealing where current AI tools may be misaligned with real work.

## Context
Current AI suitability assessments rely on static benchmark scores or expert judgments that quickly become obsolete as technology and job roles change. This framework addresses the need for dynamic, human‑centred evaluation in rapidly shifting workplace environments.

## Implications
Organizations can now prioritize pilot projects where AI aligns well with cognitive profiles, reducing risk of task failure. Practitioners gain a transparent tool to guide human‑machine collaboration and allocate duties more effectively.
