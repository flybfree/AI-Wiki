## Summary  
This paper introduces CURED, a web‑based demonstrator that lets users upload tabular data, inject realistic errors, and apply modern machine learning methods to detect and repair those mistakes. The system not only cleans the corrupted rows but also visualizes the error mechanisms behind them, bridging theory with intuitive insight.

## Key Takeaways  
- CURED combines ML‑based cleaning algorithms with a user interface that demonstrates how errors propagate in tabular datasets.  
- The demonstrator provides real‑time feedback on the type and impact of each perturbation, making abstract error models concrete for practitioners.  
- By integrating error analysis directly into data cleaning workflows, CURED offers a practical tool for validating statistical learning approaches.

## Context  
The rise of large‑scale data intensive applications demands robust error detection beyond simple rule‑based checks. Recent advances in ML have shown promise for identifying subtle anomalies, yet their deployment often lacks transparent validation. This work situates those advances within the DBMS ecosystem to make them accessible and interpretable.

## Implications  
For researchers, CURED serves as a benchmark that links theoretical error models with executable cleaning pipelines. In industry, it can reduce downstream errors in analytics, ensuring data quality without manual inspection. Practitioners gain an intuitive way to trust ML‑driven cleaning tools by seeing exactly what went wrong and how it was fixed.
