## Summary
ProTTT introduces a profile-supervised meta-learning framework that leverages test-time training to construct semantic user memory, enabling language models to continuously adapt to growing user histories without the prohibitive costs of context-based methods or the rigidity of parametric updates. By initializing shared memory parameters with supervision from textual user profiles and refining them through history-specific test-time training, ProTTT effectively captures evolving user preferences while compressing extensive interaction logs into a lightweight, parameterized representation.
