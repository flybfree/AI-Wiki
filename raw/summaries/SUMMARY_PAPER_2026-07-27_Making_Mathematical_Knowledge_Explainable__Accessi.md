## Summary
This paper proposes integrating Large Language Models with the Mathematical Model Database (MathModDB) through a Model Context Protocol server that combines natural‑language dialogue, vector‑indexed schema retrieval and a Steiner‑tree join planner to make mathematical knowledge more explainable, accessible and interoperable. The approach demonstrates improved usability over traditional Wikibase interfaces and enables seamless linking with external data repositories such as Dataverse.

## Key Takeaways
- MathModDB’s curated knowledge graph is enhanced by an LLM‑driven MCP that provides vector‑indexed schema retrieval, allowing users to query models via plain language.  
- The Steiner‑tree join planner creates efficient connections between the model database and external data stores, reducing manual API handling.  
- Two use cases in continuum mechanics and enzyme kinetics illustrate how this integration yields epistemically grounded LLM usage with higher explainability.

## Context
The work addresses a growing need for AI systems that can safely access domain‑specific knowledge without exposing users to raw, unstructured data. By marrying LLMs with structured Linked Open Data, the study exemplifies a trend toward hybrid architectures that balance generative capabilities with factual grounding.

## Implications
For researchers and practitioners, this integration lowers barriers to entry in mathematical modeling by enabling intuitive queries and automatic linking of model metadata with experimental datasets. In industry, it supports rapid prototyping and cross‑domain analysis while preserving the rigor required for scientific reproducibility.
