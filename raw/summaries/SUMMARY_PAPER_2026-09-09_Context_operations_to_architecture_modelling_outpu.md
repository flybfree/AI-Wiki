## Summary
The paper introduces a framework of formal operations to assemble context in LLM‑based engineering design and presents an evaluation method for assessing compliance between LLM outputs and intended architecture intent. It demonstrates how modular units such as policy prompts, persistent reference units, and vectored user questions can be combined systematically. Results show improved alignment and reliability compared with ad‑hoc prompting.

## Key Takeaways
- The framework structures interactions by combining policy prompts, persistent reference units, and prompt‑vectored user questions into a formal assembly process.
- A compliance evaluation method quantifies how well LLM answers match the original design intent using a structured metric.
- Modular unit integration leads to more systematic and repeatable architecture modelling workflows.

## Context
Generative AI is rapidly reshaping engineering design by offering rapid concept generation. However, without explicit control over context assembly, outputs can be inconsistent or off‑target. This paper addresses that gap by formalizing how to embed and manage context within LLM pipelines.

## Implications
Practitioners can adopt the modular framework to create more reliable AI‑assisted design tools, reducing rework caused by misaligned model responses. The evaluation protocol offers a benchmark for assessing generative models in systems architecture, supporting better integration into engineering workflows.
