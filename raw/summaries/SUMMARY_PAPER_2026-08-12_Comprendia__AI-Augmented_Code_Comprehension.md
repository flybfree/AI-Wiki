## Summary
Comprendia is an Eclipse plugin that combines a visual structural dependency graph with LLM explanations to help Java developers understand code. It demonstrates how a unified graph can support comprehension while preserving developer control, using Graph‑Aware Callee Pruning and other overlays.

## Key Takeaways
- Comprendia builds a multi‑edge‑type dependency graph that enables live search and multiple layouts, allowing developers to explore program structure interactively.
- The LLM explanations are generated by Graph‑Aware Callee Pruning (GACP), which selects relevant callees based on graph distance, inheritance collapse, and edge‑type weighting, producing reproducible prompts traceable to visible nodes.
- A clone‑detection overlay highlights duplicated code and suggests extracting functions to parent classes, while a CVE risk overlay powered by OSV.dev flags security vulnerabilities.

## Context
The paper contributes to the growing effort of augmenting human‑in‑the‑loop AI tools with domain‑specific knowledge graphs. By grounding LLM outputs in visual program structures, Comprendia addresses the challenge of hallucinated or irrelevant explanations that plague many code‑comprehension assistants.

## Implications
For developers, this integration reduces cognitive load and improves code understanding without requiring deep expertise. For industry, it offers a scalable framework for embedding AI assistance into IDEs, enhancing productivity and security awareness across large Java codebases.
