## Summary
This paper presents a self-evolving harness framework where a single frozen language model iteratively improves its own agent execution code by acting as both solver and proposer across diverse task domains. The method achieves significant generalization gains, surpassing Codex on in-distribution benchmarks and matching or exceeding it on out-of-distribution evaluations through a process framed as multi-task pretraining followed by continual training.
