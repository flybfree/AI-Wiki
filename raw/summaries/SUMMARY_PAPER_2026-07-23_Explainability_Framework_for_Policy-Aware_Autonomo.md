## Summary
The paper proposes an explainability framework for policy‑aware autonomous agents using Answer Set Programming and Python; it leverages AI penalties to detect undesirable events and generate contrastive explanations, which were evaluated through a human survey showing participants found the generated explanations informative and trustworthy.

## Key Takeaways
- The framework integrates policy enforcement with explanation generation, allowing detection of counterfactual undesirable events.  
- It leverages AI penalties as a mechanism to identify when actions would have caused negative outcomes if not taken.  
- Human evaluation shows participants find the generated contrastive explanations informative and trustworthy.

## Context
In AI, autonomous agents increasingly make decisions without human oversight; explainability is crucial for accountability. This work addresses policy‑driven behavior which can be opaque, offering a method to translate technical constraints into understandable narratives.

## Implications
Practitioners can embed this framework in rule‑based systems to provide transparent reasoning, improving trust and compliance with regulations. It also highlights the value of contrastive explanations in debugging autonomous agents.
