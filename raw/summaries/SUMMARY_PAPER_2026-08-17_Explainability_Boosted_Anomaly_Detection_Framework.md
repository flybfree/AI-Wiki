## Summary
This paper presents an explainable artificial intelligence framework designed to detect malicious traffic in O‑RAN based NextG networks with high accuracy and low runtime cost. The study evaluates multiple AI models, showing that post‑hoc explainability reduces dataset complexity by 80 % while preserving detection performance.

## Key Takeaways
- Explainability methods cut dataset size dramatically, achieving an 80 % reduction without sacrificing detection accuracy.  
- Critical attack indicators identified include protocol type, bandwidth usage, interval length, and traffic duration.  
- The framework balances computational efficiency with high detection precision, making it suitable for real‑world O‑RAN testbeds.

## Context
Explainable AI is essential as network security threats grow more sophisticated in the transition to 6G. By integrating post‑hoc explainability into anomaly detection, researchers can make model decisions interpretable, which is crucial for regulatory compliance and trustworthy deployment in dense cellular environments.

## Implications
Practitioners will benefit from a practical tool that reduces data preprocessing overhead while maintaining robust security monitoring. This approach accelerates rollout of secure NextG services and sets a precedent for future AI‑driven network protection solutions.
