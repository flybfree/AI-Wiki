## Summary  
The paper presents an LLM-driven approach for automated model interoperability within the automotive Model‑Driven Engineering (MDE) ecosystem, addressing two core challenges: mapping instances to a target metamodel and merging source and target metamodels. The methodology employs Ecore and SysML v2 transformations with structural validation against user‑defined models. Experiments show that large language models can drastically cut manual transformation effort while generating structurally valid cross‑tool model instances.  

## Key Takeaways  
- Mapping model instances to a target metamodel is automated via LLM processing, ensuring semantic alignment.  
- Merging of source and target metamodels is handled by the system, creating unified representations.  
- Structural validation against user-defined target models guarantees correctness.  

## Context  
In the broader AI landscape, large language models excel at natural language processing and code generation but have limited direct integration with engineering domain workflows. This research demonstrates a concrete application of LLMs to MDE interoperability, showing how generative AI can automate complex model transformations.  

## Implications  
For automotive manufacturers, this reduces time spent on data migration between simulation tools, improving reliability and enabling rapid prototyping. Practitioners benefit from a scalable framework that can be extended to other industries requiring heterogeneous model integration.
