## Summary
The paper introduces Drawing-Recode, a framework that generates parametric CAD code from raster‑format 2D drawings by linking dimensional annotations to geometric features. Using an image encoder and a text recognizer, the model explicitly grounds each annotation to its corresponding geometry via cross‑attention and an Annotation Grounding Loss (AGL). The resulting multimodal features are fed into a large language model that outputs Structured Parametric CAD Code (SPCC) format. Experiments demonstrate superior performance over existing baselines on scanned industrial drawings.

## Key Takeaways
- It extracts geometric features with an image encoder while recognizing annotations separately through a text recognition module.
- The annotation grounding step employs cross‑attention and the Annotation Grounding Loss (AGL) to connect each annotation to its precise geometric location.
- The final output is parametric CAD code in SPCC format generated by a large language model, which outperforms prior methods on real scanned drawings.

## Context
This work addresses a key challenge in multimodal AI: integrating image and text data to produce domain‑specific outputs. By grounding annotations to geometry, Drawing-Recode demonstrates how cross‑attention mechanisms can improve the fidelity of generated code without relying solely on vectorized inputs. Such approaches are essential for advancing generative AI in technical domains.

## Implications
Digitizing raster 2D CAD drawings with Drawing-Recode enables automated part reproduction and manufacturing workflows that were previously limited by manual vectorization. Practitioners can leverage this system to reduce errors, speed up production, and support digital twin creation across industrial settings.
