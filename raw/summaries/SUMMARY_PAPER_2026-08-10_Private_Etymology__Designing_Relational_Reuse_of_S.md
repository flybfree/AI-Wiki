## Summary
The paper introduces Private Etymology, a machine‑representable relational provenance that tracks how dyadic expressions evolve across human AI interactions. It demonstrates a lifecycle model and a prototype where a language model records evidence while deterministic code decides symbol updates. The work shows that shared symbols can be reused without re‑explaining their meaning.

## Key Takeaways
- Private Etymology creates a persistent, revisable symbolic unit that records proposal, interpretation, negotiation, repair, reuse, revision, stabilization, contestation, forgetting, or retirement of a dyadic expression.  
- The system uses deterministic local code to approve updates, preventing free‑form model confidence scores from directly modifying persisted symbols.  
- Relational reuse is enabled by reactivating an expression in later sessions without full re‑explanation.

## Context
Long‑term human AI systems often treat relational meaning as a static memory value, limiting the richness of microcultures that form between users and agents. This gap hampers naturalistic dialogue where expressions are fluid and context dependent. The paper situates Private Etymology within broader efforts to model conversational microculture.

## Implications
For practitioners, Private Etymology offers a framework for designing AI companions that can evolve with users without losing track of shared symbols. For the field, it provides evidence‑grounded infrastructure that respects user agency and supports dynamic relational semantics in long‑running interactions.
